# AI 검증 — 표시값 배율 가설 탈락, 원시값 두 후보를 비교하는 AJ

기록일: 2026-09-09. 사용자 원문은 **“패시브 2.2%, 홀로멤보드 15.7%, 나머지 일치”**다. 직전 표의 기본 네 수치도 확인된 것으로 기록했다. 편성·성장·배치·악곡 선택 전 화면은 계획을 이어받으며 별도 재확인으로 저장하지 않았다.

## 1. AI 결과

리더 리리카 40/0, 멤버 아야메 40/0·토와 70/0·수영복 라덴 70/1·일반 후레아 11/0·수영복 와타메 70/1이다. 표기는 레벨/개화다.

| 항목 | 사전예측 | 실측/확인값 | 결과 |
|---|---:|---:|---|
| 멤버 파라미터 | 84,026 | 84,026 | 일치 |
| 패시브 종합력 | 13,617 | 13,617 | 일치 |
| 액티브 | 73.7% | 73.7% | 일치 |
| SP | 43.6% | 43.6% | 일치 |
| 패시브 스코어 | 2.3% | 2.2% | **표시값 배율 가설 실패** |
| 홀로멤보드 | 조건부 15.5% / 15.6% | 15.7% | 조건부 예측 실패 |
| 보드+패시브 합계 | 조건부 17.8% / 17.9% | 17.9% | 후보 범위 내 |

보드 후보는 패시브 2.3%가 맞는다는 조건에서 만든 값이었다. 실측 합계 17.9%와 패시브 2.2%를 빼면 보드 15.7%가 되는 것은 사후 산술 확인이며, 이전 보드 예측을 성공으로 바꾸지 않는다.

전체 종합력·총 스코어보너스는 미제공이다. 97,643은 멤버+패시브 종합력의 계산 소계, 135.2%는 확인된 스코어 항목의 계산 합이다. 전체 실측으로 저장하지 않았다.

## 2. 표시값에 공통 배율을 곱하는 가설은 탈락

| 같은 멤버의 리더 비교 | 스이세이 패시브 | 리리카 패시브 |
|---|---:|---:|
| Z → W | 1.5% | 1.9% |
| AG → AH | 1.7% | 2.2% |
| AB → AI | 1.8% | 2.2% |

첫 두 쌍을 맞추려면 `ceil0.1(k × 스이세이 표시값)`의 배율이 `k > 1.235294…`여야 한다. 그러나 AB/AI는 `k ≤ 1.222222…`를 요구한다. 세 쌍을 만족하는 교집합이 없으므로 이 **표시값 입력 공통 배율**은 첫 후속 검증에서 탈락했다. 계수를 다시 맞추거나 0.1%p 차이를 임의로 처리하지 않는다.

AB→AI에서는 의상 조건이 모두 꺼진 상태에서 보드가 5.7%→15.7%(+10.0%p), 패시브가 1.8%→2.2%(+0.4%p)로 변했다. 기본 액티브·SP는 같다. 리더 맥락에 따른 패시브 변화는 유지되는 관측이지만, 그 변화가 표시값의 공통 배율로 표현되지는 않는다.

## 3. 올림 전 원시값을 사용하는 두 후보는 남음

AI를 측정하기 전 고정한 대안은 다음 두 가지였다. `x`는 스이세이 편성 패시브의 올림 전 원시값으로, 표시가 1.8%라면 `1.7 < x ≤ 1.8`이라고 가정한다.

- **원시값 배율형:** 리리카 원시값 `y = k × x`
- **원시값 가산형:** 리리카 원시값 `y = x + d`

AI의 사전 허용값은 배율형 2.2%·2.3%·2.4%·2.5%, 가산형 2.2%·2.3%였다. 실측 2.2%는 둘 다 허용하므로 둘을 구분하지 못했다. 세 리더 쌍을 반영하면 배율 범위는 `1.235294… < k < 1.294117…`, 가산량은 `0.4 < d < 0.5`로 좁혀진다. 가산량의 단위는 스코어보너스 %p다.

이들은 원시 패시브 자체를 카드에서 계산하는 공식이 아니라, 실측 표시값이 허용하는 원시값을 이용한 **리더 변환 후보군**이다. 표시값 입력 방식의 실패를 이 후보들과 혼동하지 않는다.

추가로 보드+패시브의 원시 합계 모형도 정확하고 두 항목을 각각 올린다고 가정하면 원시 패시브 범위를 더 줄일 수 있다. 예를 들어 AI의 원시 합계는 `17.756757…`, 보드 표시는 15.7%이므로 패시브 원시값은 `2.1 초과 ~ 2.156757… 미만`으로 좁혀진다. 이 합계 제약을 적용한 범위도 JSON에 별도로 보존했다. 합계 모형을 정확한 원시값으로 취급하는 **추가 가정**이며 확정 사실로 기록하지 않는다.

## 4. 다음 AJ — 두 후보의 예측 범위가 갈리는 편성

현재 AI에서 **일반 후레아 11/0만 일반 카나데 80/0으로 교체**한다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 리리카 | 40/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 수영복 라덴 | 70/1 |
| 멤버 | 일반 카나데 「퍼레이드로 미소를 전달」 | 80/0 |
| 멤버 | 수영복 와타메 | 70/1 |

이는 기존 AA와 멤버·성장·멤버 보드·순서가 같다. AA의 패시브 실측 **0.8%**를 기준으로 리리카 리더에서의 값을 비교한다. Happy는 라덴·와타메 둘뿐이어서 서포트 8% 대상은 유지된다.

| AJ 항목 | 사전예측 |
|---|---:|
| 멤버 파라미터 | 100,252 |
| 의상 종합력 | **50,131** |
| 패시브 종합력 | 22,531 |
| 위 세 항목 소계 | 172,914 (전체 종합력 아님) |
| 액티브 | 71.1% |
| SP | 42.2% |
| 패시브 — 원시값 배율형 | **0.9% / 1.0% / 1.1%** |
| 패시브 — 원시값 가산형 | **1.2% / 1.3%** |
| 보드+패시브 합계 | 조건부 13.7% / 13.8% |
| 홀로멤보드 | 개별 고정 예측 없음 — 실측 필요 |

AA의 원시 패시브 범위 `0.7 < x ≤ 0.8`에 세 쌍의 공통 배율·가산량을 각각 적용하면 위 두 표시 범위가 나온다. 합계의 원시값을 함께 사용해 범위를 더 좁혀도 AJ의 두 표시 범위는 같고 서로 겹치지 않는다.

### 이번에 함께 확인할 의상 조건

AJ에는 라덴과 일반 카나데가 있어 RegLOSS 2명 조건이 충족된다. 따라서 **리리카의 파라미터 상승 의상은 활성화**되며 의상 종합력은 50,131로 예측한다. 스코어 서포트 의상 효과는 0이다.

AA/AJ는 의상 조건까지 고정한 리더 비교가 아니다. 이전 X/Y/Z에서는 파라미터 의상 효과가 켜지거나 꺼져도 액티브 75.5%·SP 43.2%·패시브 1.5%·보드 6.9%가 같았다. 이 근거를 바탕으로 이번에도 파라미터 의상이 스코어 항목에 영향을 주지 않는다는 작업 가정을 사용한다. 다른 멤버 조합까지 완전히 증명된 독립성은 아니다.

따라서 결과는 다음과 같이 해석한다.

- 패시브 0.9%~1.1%: 의상·맥락 가정 아래 가산형보다 배율형을 지지한다.
- 패시브 1.2%~1.3%: 같은 가정 아래 배율형보다 가산형을 지지한다.
- 어느 범위에도 들지 않음: 두 사전 범위가 모두 실패한 것으로 기록하고 원시값 변환과 파라미터 의상 가정을 재검토한다. 고정 예측을 바꾸지 않는다.

어느 한 범위에 맞더라도 카드만으로 기본 패시브를 계산하는 공식이나 유일한 계수가 확정되는 것은 아니다. 리리카 서포트 13.3%와 판정 보정 노드는 같이 바뀌어 원인 노드도 아직 분리되지 않는다.

같은 악곡 선택 전 화면, 기존 성장·보드 해금·배치 순서를 유지한다. 일반 카나데 콤보 100·라덴 라이프 600은 기존 모형의 충족 가정을 유지하고 아야메 가창자 조건은 제외한다. 다음 입력은 **멤버 파라미터·의상 종합력·패시브 종합력·액티브·SP와 패시브·홀로멤보드 각각의 값**이다.

## 5. 누적 결과와 기록

기본 액티브·SP는 33개 관측, 21개 서로 다른 멤버 조합을 재현한다. AI는 기존 AB 멤버 조합을 반복하므로 새 멤버 조합으로 세지 않는다. 발견 시 사후 대조 20건, 이후 새 멤버 조합 7건과 같은 멤버의 리더 변경 6건이다.

양의 서포트 패시브 합계 후보군에 호환되는 관측은 18건이다. 사후 14건과 사전 후속 AF/AG/AH/AI 4건을 구분한다. 단순 개별 효과량 계산은 계속 실패한다. 리리카 확장 대조의 G 0.1%p 잔차와 아야메 스코어 서포트 의상 식은 미해결 상태를 유지한다. 사용자 요청에 따라 인게임 설명은 참고로 보존하고 실측 재현을 우선한다.
