# AV・AX・AY 검증과 AX 보드 잔차

2026-09-09. 원문: “AV 전부 일치. AX 패시브 없음, 보드스코어 10.9%. AY 전부 일치”. AX 후속 답변은 “액티브, SP는 일치함. 나머지 보드 맞음.”이다. 후속 질문과 원문은 AX 관측 JSON에 함께 보존했다.

## 사전 예측 판정

| 편성 | 액티브 예측/실측 | SP 예측/실측 | 패시브 예측/실측 | 보드 예측/실측 | 판정 |
|---|---:|---:|---:|---:|---|
| AV | 64.2 / 64.2 | 37.3 / 37.3 | 2.4 / 2.4 | 10.3 / 10.3 | 일치 |
| AW (직전 관측) | 74.0 / 74.0 | 42.9 / 42.9 | 4.7 / 4.7 | 11.3 / 11.3 | 일치 |
| AX | 68.9 / 68.9 | 37.5 / 37.5 | 없음 / 없음 | 10.8 / 10.9 | 0.1%p 차이 |
| AY | 74.0 / 74.0 | 42.9 / 42.9 | 7.0 / 7.0 | 12.0 / 12.0 | 일치 |

AV/AY의 “전부 일치”는 사용자에게 제시했던 네 스코어 행을 확인한다. 종합력·총합은 새로 확인되지 않았다. AX 최초 답변에는 액티브/SP가 없었으며 후속 답변에서만 확인됐다. 패시브 원문 숫자는 null, 행 존재는 false로 보존하고 비교에서만0으로 정규화한다. AX 보드 설정은 사용자 확인을 받았지만 카드 육성 화면을 별도 감사한 것은 아니다.

새 후보는 사전 예측 네 조건 중3건 일치, AX1건 실패다. 이 네 조건은 서로 다른 멤버 조합3개이며 AY는 AW와 같은 조합의 보드 개입이다. 기존40건은 모형 선택에 사용한 사후 재현이다. 합쳐서 적용 대상44건 중43건을 재현하지만 이를 통계적인 정확도로 해석하지 않는다. 서포트 의상 I/J/M과 리더 보드 미확인 U는 계속 제외한다.

누적 관측48건·멤버 조합26개, 제공된 액티브44/44·SP44/44, 확인된 기본 종합력 세부106개, 양의 패시브 원시 합계 호환32건이다. AU는 여전히 미관측이다.

## 해석과 경계 검사

와타메 발동률24.5%·빈도4%를 끈 AW→AY에서 패시브+보드 표시 합16.0→19.0의 증가를 사전 예측했고 실측이 일치했다. 현재 시간창에서 스킬이 겹치는 방식을 계산하는 모형을 지지한다. 실제 악곡에서 보드를 끄면 점수가 높아진다는 증거는 아니다.

AX에는 스코어 서포트 패시브가 없다. 따라서 이0.1%p는 양의 패시브와 보드 사이의 배분으로 해결할 수 없다. 현재 고정 중간 연산에서 A_raw=68.82976325183536, BP_raw=79.60419362653994, 차이=10.774430374704579이다. 각각0.1 올림 후 차이는79.7−68.9=10.8이다. A의 끝값을 고정하면 BP가 다음 경계를 넘으려면 약0.095806보다 더 증가해야 하므로 단순 부동소수점 끝자리 오차로 보기는 어렵다. 이는 더 앞선 중간 정밀도 차이까지 배제하는 주장은 아니다.

중간 모형·가중치를 고정하고 끝값의 올림/버림/반올림9조합과 원시 차이의3처리, 합12설정을44건에 적용했다. 최대43/44로 전체 일치는 없다. BP 올림−A 버림은 AX10.9를 만들지만 나머지43건을 깨뜨린다. BP 올림−A 반올림도 AX를 맞추지만15/44에 그친다. 이 제한된 검사로 모든 가능한 계산식이 불가능하다고 주장하지 않는다. 관측 후 진단은 사전 검증 성공으로 세지 않는다.

노엘 발동률21.5/23.5, 빈도4, 카나데 발동률20의 입력 대안도 기록했지만 사용자 확인으로 원래 요청한 보드 상태가 지지됐다. 입력을 임의 수정하거나 AX 전용 보정 상수를 넣지 않는다. 서비스 계산식은 변경하지 않았다.

## 다음 AZ: AX에서 노엘 발동률만 모두 OFF

리리카3성「We are hololive!」1/0 리더, 아야메40/0 → 토와70/0 → 수영복 노엘80/1 → 수영복 스이세이60/0 → 수영복 카나데40/0을 유지한다. 악곡 선택 전 화면을 확인한다.

노엘의 남은 발동률11.1%·3.7%·3.0%를 모두 끈다. 노엘 빈도와 카나데 발동률15%·5%는 계속OFF, 리리카 서포트6.2%·4%·3.1%=13.3%와 판정 노드는ON이다. 전체 보드를 초기화하지 않는다. 연결 때문에 다른 효과까지 꺼져야 하면 그 변경도 기록한다.

**사전 예측: 패시브 없음 / 보드9.2%, 액티브68.9% / SP37.5%.** 고정 파일은 `experiments/baseline-noel-off-AZ-20260909.json`이다. 중간 정밀도 처리를 하지 않는 기존 대안은 보드9.1이다. AX의0.1 차이가 그대로 남는다는 단순 외삽은9.3이지만 채택한 모형이 아니다.

AZ는 멤버 발동 관련 보드가 없는 기준점을 확인한다. 맞으면 AX의 추가 발동률을 적용할 때 잔차가 생기는 방향을 좁힐 수 있고, 틀리면 멤버 발동 보드가 없어도 문제가 남는다는 뜻이다. 단독으로 판정 노드의 기여가0이거나 내부식이 유일함을 증명하지 않는다.

## 재현

`node scripts/test-validation-av-ax-ay.mjs`로 이번 관측·실패·끝값 검사와 AZ 고정 예측을 재현한다. `node verify-handoff.mjs`는 이전 체크포인트도 보존해 검사한다. 테스트 PASS는 기록과 재계산의 일치를 뜻하며 AX 예측 실패를 성공으로 바꾸지 않는다.
