# AC 검증과 보드 표시 처리 비교 AD — 2026-09-09

AC는 멤버 파라미터·패시브 종합력·액티브·SP와 패시브 스코어 항목 없음이 예측과 같다. **보드는 사전 1.6%에 대해 실측 1.5%로 실패**했다. 서포트 패시브가 없는 이번 편성에서도 차이가 나므로, 기존 원시 합 후보의 오차를 보드·패시브 두 항목의 개별 올림만으로 처리하는 설명은 충분하지 않다.

AC를 재현하는 표시 처리 대안은 세 가지가 남는다. 다음 AD는 **일반 카나데 80/0을 수영복 카나데 40/0으로만 교체**하여 멤버 캐릭터별 보드 입력을 유지한다. 액티브 **71.3%**, SP **41.6%**, 보드 후보 **5.3% 대 5.4%**를 사전 저장했다. 하나의 보드 공식을 확정하지 않았다.

## AC 실측과 사전 비교

사용자 답변은 **“모두 사전예측과 동일하고 보드 1.5%, 패시브 항목없음”**이다. 직전 대화의 AC 표에 있던 네 수치의 일치를 확인한 것으로 기록했다.

| 항목 | 사전 예측 | 확인 결과 |
|---|---:|---:|
| 멤버 파라미터 | 86,545 | 86,545 |
| 패시브 종합력 | 17,476 | 17,476 |
| 액티브 | 68.4% | 68.4% |
| SP | 40.7% | 40.7% |
| 보드 스코어 | **1.6%** | **1.5%** |
| 패시브 스코어 | 0 또는 항목 없음 | **항목 없음** |

패시브 스코어의 숫자 필드는 null로 보존하고, 항목 없음은 별도 상태로 기록했다. 표시 기여를 비교할 때만 확인된 부재를 0으로 취급한다. 카드를 계획대로 사용한 것으로 채택했으며 성장값·화면을 별도로 재확인했다고 표시하지 않았다.

직전 대화 표에는 전체 종합력과 총 스코어 보너스가 없었으므로 이 둘을 이번 답변으로 확인했다고 처리하지 않는다. 멤버+패시브 종합력 합은 **104,021**, 확인된 스코어 항목 합은 **68.4 + 1.5 + 40.7 = 110.6%**다. 둘 다 계산한 합이며, 각각 전체 종합력·직접 확인한 총 스코어 보너스로 대체하지 않는다. 의상 종합력·의상 스코어의 개별 미제공도 유지한다.

기본 액티브·SP 후보는 **27건·서로 다른 멤버 조합 18개**를 재현한다. SP 정밀도 규칙 발견 당시 20건은 사후 비교, W/AA/AB/AC는 이후 새 멤버 조합 확인, X/Y/Z는 같은 멤버 조합의 리더 변경 확인이다. 모든 관측을 독립 사전 예측 성공으로 세지 않는다.

## 보드 표시값 1.5%를 만드는 후보

기존 원시 계산은 보드 발동률을 기본 확률에 상대적으로 곱하고, 발동 간격을 `1 + 발동 빈도/100`으로 나눈다. 간격은 반올림하지 않고 200초 가중 액티브를 계산한다. 아래 수치는 게임 내부 원시값을 읽은 것이 아니라 이 연구 후보에서 계산한 값이다.

- 기본 액티브 원시값: **68.3087500** → 표시 후보 **68.4%**
- 보드 반영 액티브 원시값: **69.8470527** → 표시 후보 **69.9%**
- 두 원시값 차이: **1.5383027**

| 표시 처리 가설 | AC 계산 | 실측 1.5%와 비교 |
|---|---:|---|
| 원시 증가량을 0.1 올림 — 기존 사전 후보 | 1.6% | **실패** |
| 원시 증가량을 0.1 반올림 | 1.5% | 사후 일치 |
| 원시 증가량을 0.1 버림 | 1.5% | 사후 일치 |
| 보드 반영 전후 액티브를 각각 0.1 올림한 뒤 차감 | 69.9−68.4 = 1.5% | 사후 일치 |

마지막 방식은 `보드 반영 원시 액티브 − 표시 액티브`를 0.1 올림하는 방식과 수학적으로 같다. 같은 규칙을 서로 다른 독립 후보로 세지 않는다.

발동률 적용 2종×빈도 적용 2종×간격 처리 4종×표시 처리 4종의 **64개 설정**을 비교했다. 시험한 범위에서는 기존의 상대 발동률·빈도 분모·간격 미반올림 원시 계산에 위 세 표시 처리를 적용한 경우만 1.5%를 재현했다. 이는 전체 가능한 식의 유일성이나 게임 내부 200초 설정의 증명이 아니다.

AC 한 건으로 세 대안을 구분할 수 없다. 또한 이 대안들은 **스코어 서포트 패시브가 없는 편성**의 보드 표시를 위한 비교다. Z/AA/AB의 양의 패시브와 보드 사이 배분식을 해결한 것으로 확대하지 않는다. AB의 7.4→7.5 실패와 AC의 1.6→1.5 실패는 각각 그대로 남긴다.

## 다음 AD: 같은 캐릭터의 카나데 카드 교체

AC의 **일반 카나데 80/0만 수영복 카나데 40/0으로 교체**한다. 리더와 다른 네 멤버의 카드·성장값·보드 해금 상태를 유지한다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 수영복 스이세이 | 60/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 라덴 | 70/1 |
| 멤버 | 일반 후레아 「하프 엘프의 바람이 스치는 곤돌라」 | 11/0 |
| 멤버 | **수영복 카나데** | **40/0** |

멤버 캐릭터 구성은 같으므로 기록된 보드 발동률/빈도도 아야메 0/0, 토와 0/0, 라덴 14/4, 후레아 6/0, 카나데 20/0으로 유지된다. 아야메의 가창자 조건부 노드는 기존 악곡 선택 전 조건에 따라 제외한다. 스이세이 의상 조건은 계속 불충족이며 관련 리더 보드도 없다.

카나데 카드 교체는 액티브·SP·능력치·종합력 패시브를 바꾸지만, 스코어 서포트 패시브는 계속 없다. 각 변화는 기존 계산으로 별도 검산한다. 후레아 40콤보와 라덴 라이프 600 조건은 기존처럼 충족으로 취급한다.

| AD 사전 예측 | 값 |
|---|---:|
| 멤버 파라미터 | **76,437** |
| 패시브 종합력 | **12,553** |
| 의상 종합력 | 0 |
| 위 세 종합력 항목 합 | 88,990 |
| 액티브 | **71.3%** |
| SP | **41.6%** |
| 패시브 스코어 | **0 또는 항목 없음** |

AD의 후보 원시 액티브는 **71.2179531**, 보드 반영 원시 액티브는 **76.5906295**, 차이는 **5.3726764**다.

| AC를 통과한 표시 처리 대안 | AD 보드 사전 예측 |
|---|---:|
| 원시 증가량 반올림 | **5.4%** |
| 원시 증가량 버림 | **5.3%** |
| 반영 전후 액티브 각각 올림 후 차감 | 76.6−71.3 = **5.3%** |

참고로 AC에서 실패한 기존 원시 증가량 올림도 AD에서는 5.4%다. AD가 5.4%여도 AC에서의 실패가 사라지는 것은 아니다.

- **5.3%**라면 이번 새 편성에서는 버림/표시값 차감 쪽을 지지한다. 두 방식은 여전히 구분되지 않는다.
- **5.4%**라면 현재 원시 계산을 전제로 반올림 쪽을 지지한다. 한 번의 일치로 범용 공식을 확정하지 않는다.
- **다른 값**이면 임의 보정을 추가하지 않고 원시 계산과 적용 조건을 다시 검토한다.

다른 스코어 기여가 없을 때 항목 합은 보드 5.3이면 **118.2%**, 보드 5.4이면 **118.3%**다. 아직 단일 총합 예측으로 정하지 않는다.

AD에서는 **멤버 파라미터·패시브 종합력·액티브·SP·보드의 정확한 표시값·패시브 항목 유무**를 확인한다. 총 스코어 보너스도 제공되면 합을 검산한다.
