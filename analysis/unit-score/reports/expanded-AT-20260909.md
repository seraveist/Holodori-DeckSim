# 중간 정밀도·배분 방식 확장 — AT까지

2026-09-09. 사용자의 “검사식을 좀 더 확장해보면 어때?” 요청에 따라 기존29건의 반올림 검사보다 앞선 연산과 배분 방식을 탐색했다. **알려진 숫자 보드를 비교할 수 있는40건에서 패시브·보드 표시값을 모두 재현하는 공통 후보가 나왔다.** 같은 자료를 보고 선택한 사후 결과이므로 인게임 내부식의 확정이나 독립 예측 성공으로 보지 않는다. 서비스 계산식은 변경하지 않았다.

## 탐색 범위

첫 단계는 양의 서포트 패시브29건을 사용했다. 발동률, 주기, 스킬 효과량, 확률 합 분모, 멤버별 분자·정규화 기여, 매초 합계, 적분 후 멤버별 기여에0~4자리 올림·버림·반올림을 적용했다. 단정밀도 입력 변환과 리더·패시브 곱셈도 별도 비교했다. 기존 액티브 표시를 유지한 후보만 배분 비교에 넣었다.

배분은 기존 평균 횟수 비례 외에 정수 횟수, 실제 표본에서 켜진 시간, 중첩 정규화 후 기여 가중치, 보드 우선·패시브 우선 차감, 양 순서의 평균을 비교했다. 중간 합계와 최종 두 행의 올림·버림·반올림도 조합했다. 총31,698개 설정을 비교했고,29건을 모두 맞춘 설정은4개였다. 이4개는 효과량0.1 올림 또는 확률 합 분모0.001 버림이라는 두 중간 처리에, 양 끝값 올림/버림이라는 구별되지 않는 두 선택을 조합한 것이다.

두 번째 단계에서는 이 두 중간 처리에 다른 정밀도 처리 한 곳을 더하는180개 설정을 비교했다. 끝값·최종값 올림과 평균 횟수 배분을 고정하고 무패시브11건도 평가에 포함했다. **효과량0.1 올림과 발동률0.1%p 올림을 함께 적용한 설정이40건을 모두 재현했다.** 180개는 설정 수이며 전 세계의 가능한 공식이나 서로 다른 수학적 함수 수가 아니다. 이미 알려진 G도 선택에 사용했으므로 독립 검증으로 세지 않는다.

## 새 공통 후보

각 멤버에 대해 기존 조건을 판정한 기본 효과량을 v, 보드를 반영한 발동확률을 p, 리더 보드 서포트를 L, 해당 멤버가 받는 서포트 패시브를 s라 둔다. 보드·패시브를 적용하지 않는 기준 계산에서는 그 값을0으로 둔다.

1. 발동률 보드 적용 후 `p' = ceil(p × 1000) / 1000`. 예를 들어64.79%는64.8%가 된다. 확률의0.001은 표시 퍼센트의0.1%p다.
2. 서포트를 더한 효과량을 `v' = ceil0.1(v × [1 + (L+s)/100])`로 정리한다. 예를 들어135.96% 효과량은136.0%가 된다.
3. 기존200초·1초 표본 커널에서 `Σ(p'v') / max(1,Σp')`를 적분한다. 첫 발동은 주기 경과 후이며 보드 빈도에 따른 주기 나눗셈은 유지한다.
4. `Q = ceil0.1(BP_raw) − ceil0.1(A_raw)`를 구하고, 기존 평균 횟수 가중치로 패시브와 보드에 배분한 뒤 각 행을0.1 올림한다.

배분 가중치는 이전 식을 유지한다. `w = 기본 p × 기본 v × 지속시간 / 기본 주기`, `PW = Σ(w × s)`, `BW = Σ(w × 100 × [(1+r/100)(1+f/100)(1+L/100)−1])`다. 패시브 원시는 `Q×PW/(PW+BW)`, 보드 원시는 그 나머지다. r/f는 멤버 발동률/빈도 보드다. 시간 커널의 L+s 가산과 배분용 가중치의 곱을 혼동하지 않는다.

새 처리에는 표본별 예외, 카드별 보정 상수, 자유롭게 맞춘 곡 길이, 보드 노드의 추정 내부 수치나 임의 판정 확률이 없다. 다만 두 정밀도 처리의 선택 자체는 데이터를 본 뒤 이루어진 모형 선택이다.

이40건 중 액티브가 실제 제공된36건은36/36 유지한다. AK·AO·AS·AT의 액티브/SP는 여전히 미제공이다. 전체 기존 자료의 액티브/SP40/40 기록과 이 하위 범위의36/36을 혼동하지 않는다. 패시브 항목이 없는 자료는 비교용으로만0을 사용하며 원문 null/행 부재를 수정하지 않는다.

독립적인 정수 연산 구현으로 발동확률·효과량·발동창을 다시 계산해40건의 원시 A/P/B/BP 모두 오차1e-8 이내로 일치하는지 검사한다. 멤버 순서를 뒤집어도 표시 결과가 유지되는지 검사한다. 이는 구현 재현 검사이며 인게임의 새로운 실측40건을 뜻하지 않는다.

## 남은 범위와 다음 검증

- 서포트 의상 I/J/M과 미확인 리더 보드 U는 제외했다. 전체44건 모두가 검증됐다는 의미가 아니다.
- 보드·메모리·강화 종합력, 최종 유닛스코어와 실제 곡 플레이 점수까지 이번 결과로 확정하지 않는다.
- 새 식의 사전 예측 성공은 아직0건이다. 기존 AR의 실패와 재확인은 새 후보의 독립 성공으로 바꾸지 않는다.
- AU는 미관측 상태다. 새 후보에서 판정 노드는 별도 수치 기여를 넣지 않으므로 AS와 같은 **패시브3.0%/보드10.1%**를 예측한다. 실제 AU가3.0%/10.0%라면 이 모형에서 생략한 판정 기여를 다시 검토해야 한다. 기존 AU의 두 가설도 보존한다.
- 새 자료2~3건의 사전 예측을 비교하기 전에는 생산 계산식으로 승격하지 않는다. 이후 실패가 나오면 후보식과 실패를 함께 기록하고, 결과별 예외 보정은 추가하지 않는다.
