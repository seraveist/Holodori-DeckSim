# AG 검증 — 노엘 서포트 9%와 리더만 바꾸는 AH

기록일: 2026-09-09. 사용자 원문은 **“홀로멤보드 5.3%, 패시브스킬 1.7%, 나머지 일치”**다. 직전 AG 예측 표의 네 기본 수치도 일치한 것으로 저장했다. 레벨·개화·악곡 선택 전 화면은 계획을 이어받았으며 별도로 재확인된 것으로 기록하지 않았다.

## 1. AG 결과

리더 수영복 스이세이 60/0, 멤버 아야메 40/0·토와 70/0·수영복 라덴 70/1·일반 후레아 11/0·수영복 노엘 80/1이다. 표기는 레벨/개화다.

| 항목 | 고정 사전예측 | 실측/확인값 |
|---|---:|---:|
| 멤버 파라미터 | 86,545 | 86,545 |
| 패시브 종합력 | 10,772 | 10,772 |
| 액티브 | 74.6% | 74.6% |
| SP | 44.3% | 44.3% |
| 홀로멤보드 | 개별 예측 없음 | 5.3% |
| 패시브 스코어 | 개별 예측 없음 | 1.7% |
| 보드+패시브 합계 | 조건부 후보 7.0% 또는 7.1% | 7.0% |

전체 종합력·총 스코어보너스는 미제공이다. 97,317은 멤버+패시브 종합력의 계산 소계, 125.9%는 확인된 스코어 항목의 계산 합이다. 원시 관측의 전체 수치와 미제공 의상·기타 종합력 항목은 `null`로 보존했다.

AG는 스코어 서포트 패시브 제공자가 노엘 하나이며, 3기생도 노엘·일반 후레아 두 명뿐이다. 따라서 9% 서포트 대상은 이 둘로 좁혀진다. 와타메·수영복 후레아의 8% 서포트는 없는 구성이다. 다른 종합력 패시브는 따로 적용된다.

## 2. 합계 모형은 유지, 개별 배분은 미확정

고정한 원시 모형의 AG 값은 다음과 같다.

- 보드 제외 액티브 `Araw = 74.560833…`
- 보드만 반영 `Braw = 78.525039…`
- 보드와 대상별 서포트를 함께 반영 `BPraw = 81.469031…`
- 원시 합계 증가분 `BPraw − Araw = 6.908198…`

마지막 값이 실제 두 항목의 원시 합이며, 두 항목을 각각 소수 첫째 자리까지 올린다는 가정 아래 표시 합계는 7.0% 또는 7.1%다. 실측 `5.3 + 1.7 = 7.0%`는 그 범위에 들어간다. AF에 이어 다른 서포트 제공자·조건에서도 사전에 고정한 합계 후보군이 유지됐다.

이 후보군에 호환되는 양의 서포트 패시브 관측은 16건이다. 그중 14건은 후보군을 정리할 때 이미 있던 사후 대조이며, AF·AG 두 건은 후속 사전 검증이다. 개별 보드·패시브 공식이 16건 맞았다는 뜻은 아니다.

기존 단순 배분식은 AG에서 보드 `78.6 − 74.6 = 4.0%`, 패시브 `81.5 − 78.6 = 2.9%`를 내므로 실측 5.3% / 1.7%와 다르다. 이 값은 사전 계획에도 실패한 방식의 진단 참고값으로만 기록했다. 노엘의 단일 9% 서포트에서도 실패하므로 와타메·후레아의 8% 서포트에만 한정된 문제는 아니다.

기존 Z/AA/AB/AF에서 배제한 공통 배율 보정도 계속 배제한다. 네 편성에 허용되는 배율 구간이 이미 겹치지 않으므로 AG가 그 방식을 되살리지는 않는다. 편성별 임의 보정값은 추가하지 않았다.

패시브 없는 스이세이 리더 AC/AD/AE의 보드 표시값 차감식, 리리카 보드 확장 대조의 G 0.1%p 잔차, 아야메 스코어 서포트 의상 미확정 상태는 그대로다.

## 3. 액티브·SP 교차 확인

AG까지 기본 액티브·SP 표시값은 31개 관측, 21개 서로 다른 멤버 조합을 재현한다. 모형 발견 당시 사후 대조 20건과 후속 검증 11건을 구분한다. 후속 중 새 멤버 조합은 W/AA/AB/AC/AD/AF/AG 일곱 건, 같은 멤버의 리더 변경은 X/Y/Z/AE 네 건이다.

AG의 SP 44.3%는 액티브 **표시값 74.6%를 입력**하는 기존 모형과 맞는다. AG 계획에 미리 저장한 원시 액티브 입력 방식은 44.2%, 발동률을 지속시간으로 가중하는 방식은 44.5%여서 각각 맞지 않는다. 다만 AG의 카드별 SP 서포트 항은 이미 소수 둘째 자리에서 정확하므로, 카드별 서포트 올림 여부를 새로 구분하는 사례는 아니다. 멤버 보드와 서포트 패시브는 기본 액티브·SP 계산에서 계속 제외한다.

## 4. 다음 AH — 멤버 고정, 리더만 리리카로 변경

**현재 AG에서 리더 수영복 스이세이 60/0만 리리카 40/0으로 교체한다.** 멤버 다섯 장과 성장·보드 해금·배치 순서는 그대로 둔다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 리리카 | 40/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 수영복 라덴 | 70/1 |
| 멤버 | 일반 후레아 「하프 엘프의 바람이 스치는 곤돌라」 | 11/0 |
| 멤버 | 수영복 노엘 | 80/1 |

AG의 스이세이 의상 조건은 꺼져 있다. AH도 RegLOSS 멤버가 라덴 한 명뿐이므로 리리카의 RegLOSS 2명 조건을 충족하지 않는다. 따라서 **두 편성 모두 의상 효과가 꺼진 상태에서 리더 변경을 비교**한다. 노엘의 서포트 대상·수치와 멤버의 액티브·SP 조건, 멤버 보드 입력도 동일하다.

| AH 항목 | 고정 사전예측 |
|---|---:|
| 멤버 파라미터 | 86,545 |
| 의상 종합력 | 0 (조건 꺼짐) |
| 패시브 종합력 | 10,772 |
| 위 세 항목 소계 | 97,317 |
| 액티브 | 74.6% |
| SP | 44.3% |
| 홀로멤보드 | 개별 예측 없음 — 실측 필요 |
| 패시브 스코어 | 개별 예측 없음 — 실측 필요 |

리리카의 확인된 리더 보드는 무조건 스코어 서포트 합 13.3%, 20초마다 낮은 확률로 7초간 GOOD 이상을 PERFECT로 만드는 판정 보정, 가창자 포함 시 전원 서포트 24%다. 같은 악곡 선택 전 화면을 사용해 가창자 조건 효과를 제외하는 계획이다. 판정 보정의 확률 숫자는 미확인이다.

현재 수치 모형은 서포트 13.3%를 넣고 판정 보정 기여는 계산하지 않는다. 이에 따른 AH 원시 합계 증가분은 `17.352028…`이며, 두 항목의 별도 올림을 가정한 **보드+패시브 합계 후보는 17.4% 또는 17.5%**다. 이는 조건부 후보군이며, 판정 보정을 무관하다고 확정한 계산식이 아니다. 개별 보드·패시브는 예측하지 않는다. 기존에 실패한 단순 배분의 14.4% / 3.0%는 JSON에 진단 참고값으로만 남겼다.

이전에 W/Z에서는 같은 멤버·의상 조건 꺼짐 상태에서 리더를 스이세이에서 리리카로 바꾸자 패시브가 1.5%에서 1.9%로 변했다. AH는 다른 제공자인 노엘 9%에서도 같은 종류의 관계가 나타나는지 확인한다. 이전 차이 +0.4%p나 비율을 AH에 그대로 적용하지 않는다.

- AH 패시브가 AG의 1.7%와 달라지면, 이 노엘 편성에서도 의상이 꺼진 상태의 리더 맥락이 패시브 표시에 영향을 주는 증거가 된다. 서포트 노드와 판정 노드 중 어느 쪽인지는 분리하지 못한다.
- 같으면 이 편성의 표시 정밀도에서 변화가 없는 것이다. 기존 W/Z의 차이가 사라지거나 일반적인 독립성이 증명되는 것은 아니다.

라덴 라이프 600·일반 후레아 콤보 40 조건은 기존 모형의 충족 가정을 유지한다. 아야메 가창자 조건은 악곡 선택 전 맥락에서 제외한다. 전체 종합력은 리더 변경에 따른 보드·메모리·강화 내역이 제공되지 않아 고정 예측하지 않는다.

다음 입력은 멤버 파라미터·패시브 종합력·액티브·SP와 **홀로멤보드·패시브 스코어 각각의 값**이다. 총 스코어보너스가 있으면 별도로 검산한다.
