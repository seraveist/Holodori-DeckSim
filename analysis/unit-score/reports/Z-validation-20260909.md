# Z 검증과 리더 보드·패시브 관계 정리 — 2026-09-09

Z의 최초 다섯 항목과 후속 패시브 종합력 12,584가 사전 계산 또는 유지 가설과 일치한다. 후속 답변으로 전체 종합력 133,702와 총 스코어 보너스 127.1%도 확인했다. 의상 효과가 꺼져 있고 관련 리더 보드도 없는 스이세이에서 패시브 1.5%, 보드 6.9%가 유지됐다. W의 리리카에서만 패시브 1.9%, 보드 17.3%가 나타나는 차이는 이제 종합력 의상보다 리더 보드와 관련된 추가 기여라는 설명을 더 강하게 지지한다. 특정 보드 노드의 인과관계나 범용 계산식까지 확정한 것은 아니다.

## Z 실측과 사전 예측

수영복 스이세이 60/0 리더, 아야메 40/0·토와 70/0·라덴 70/1·수영복 노엘 80/1·수영복 와타메 70/1의 Z 계획에 대한 응답으로 기록했다. 성장값과 화면은 계획대로 채택했으며 별도 재확인한 것으로 처리하지 않았다.

| 항목 | 사전 계산·가설 | 실측 |
|---|---:|---:|
| 멤버 파라미터 | 100,252 | 100,252 |
| 패시브 종합력(후속 입력) | 12,584 | 12,584 |
| 액티브 | 75.5% | 75.5% |
| SP | 43.2% | 43.2% |
| 패시브 유지 가설 | 1.5% | 1.5% |
| 보드 유지 가설 | 6.9% | 6.9% |

최초 응답에서 생략됐던 전체 종합력·패시브 종합력·총 스코어 보너스는 후속 입력 **“z의 전체 종합력 133702 패시브 스킬 12584, 스코어보너스 127.1%임”**으로 보완했다. 같은 Z 관측의 추가 정보이며 새 편성으로 세지 않는다.

멤버 파라미터와 패시브 종합력의 합은 **100,252 + 12,584 = 112,836**으로 사전 비교용 계산과 같다. 전체 종합력에서 두 항목을 뺀 나머지는 **133,702 − 112,836 = 20,866**이다. 의상 종합력은 여전히 개별 미제공이며, 계획상 의상 조건 불충족으로 0을 가정하면 이 나머지는 보드·메모리·강화의 합이다. 개별 기여는 임의 배분하지 않았다.

이제 총 스코어 보너스 **127.1%**가 직접 확인됐으며, 기존 네 항목 합 **75.5 + 1.5 + 43.2 + 6.9 = 127.1%**와 일치한다. 표시 보드 제외 합은 **120.2%**다. 의상 스코어 보너스는 개별 미기재 상태를 유지한다.

액티브와 SP 연구 후보는 **24건·서로 다른 멤버 조합 15개**를 재현한다. SP 정밀도 규칙 발견 당시 20건은 사후 비교, W는 새 멤버 조합의 구분 검증, X/Y/Z는 동일 멤버의 리더·의상 교체 확인이다. 24건을 모두 독립 사전 예측 성공으로 세지 않는다.

## 네 편성의 대조 결과

| 편성 | 리더 | 종합력 의상 상태 | 관련 리더 보드 | 패시브 | 보드 표시 |
|---|---|---|---|---:|---:|
| W | 리리카 | 조건 불충족 | 서포트 13.3%, 판정·가창자 조건 노드 | 1.9% | 17.3% |
| X | 수영복 카나데 | 퍼포먼스 130% | 없음 확인 | 1.5% | 6.9% |
| Y | 일반 카나데 | 센스 130% | 같은 카나데 | 1.5% | 6.9% |
| Z | 수영복 스이세이 | 조건 불충족 | 없음 확인 | 1.5% | 6.9% |

네 편성의 멤버 파라미터, 액티브, SP는 각각 100,252·75.5%·43.2%로 같다. 의상 불충족 상태는 카드와 계획된 멤버 조건에서 계산했으며, W/Z의 의상 종합력은 미기재 원본을 그대로 보존한다.

X/Y/Z에서 종합력 의상은 퍼포먼스 강화, 센스 강화, 효과 없음으로 달라져도 패시브는 1.5%로 유지된다. 특히 W/Z는 모두 의상 조건이 불충족이다. 그 상태에서 리리카는 스이세이보다 **패시브 +0.4%p, 보드 표시 +10.4%p**이고 액티브·SP는 같다. 이 결과는 W/X의 패시브 차이를 단순히 종합력 의상의 유무로 설명하는 가설과 맞지 않는다.

현재 작업 가설은 **리더 보드 또는 리더에 따른 기여 배분이 패시브 표시에도 영향을 준다**는 것이다. 따라서 보드 항목이 별도로 표시된다는 이유만으로 패시브 계산과 완전히 독립이라고 가정하지 않는다. 기본 액티브·SP는 기존 보드 제외 후보를 유지하고, 패시브에는 리더 보드 상호작용을 별도로 검증한다.

다음 범위는 아직 미확정이다.

- W/Z는 리더 캐릭터도 다르므로, 특정 리리카 보드 노드만의 인과관계를 직접 분리한 결과는 아니다.
- 패시브 +0.4%p는 이 멤버 조합에서의 실측 차이다. 다른 편성에 고정 가산하지 않는다.
- 세 서포트 노드 합 13.3%를 기준 패시브에 단순히 곱하는 방식은 1.5→1.9를 설명하지 못한다. 일반 상호작용 식을 찾은 것은 아니다.
- 악곡 미선택 화면이므로 가창자 24%를 무조건 합산하지 않는다. 판정 보정의 낮은 확률도 수치로 임의 확정하지 않는다.
- 이번 대조는 파라미터만 올리는 의상에 관한 것이다. 아야메의 스코어 서포트 60% 의상까지 영향이 없다고 일반화하지 않는다.
- 관련 **리더** 보드가 없다는 뜻이지 멤버 보드까지 없는 것은 아니다. 보드 표시 6.9%의 개별 기여 계산은 미확정이다.

이제 이 다섯 멤버에서 리더 서포트 의상·관련 리더 보드가 없는 패시브 기준점은 **1.5%**로 확보했다. 일반 패시브 계산식을 좁히려면 새 멤버 조합의 기준점이 더 필요하다.

## 다음 AA: 노엘만 일반 카나데로 교체

Z의 수영복 노엘 80/1을 일반 카나데 80/0으로 바꾼다. 리더와 나머지 네 멤버는 유지한다. 스이세이 의상 조건은 여전히 불충족이고 관련 리더 보드는 없다.

Happy 멤버는 여전히 와타메·라덴 두 명뿐이며, 와타메 패시브는 두 명에게 각 8% 서포트로 동일하다. 두 대상의 액티브 성능과 와타메의 Happy 2명 조건도 유지된다. 일반 카나데는 종합력 패시브를 추가하지만 스코어 서포트 패시브를 추가하지 않는다.

| AA 사전 검산·예측 | 값 |
|---|---:|
| 멤버 파라미터 | 100,252 |
| 의상 종합력 | 0 |
| 패시브 종합력 | **22,531** |
| 위 세 항목 합 | 122,783 |
| 액티브 | **71.1%** |
| SP | **42.2%** |
| 패시브: 두 수혜자만으로 결정된다는 유지 가설 | **1.5%** |

SP 서포트×지속시간 합은 6,160으로 같고, 유효 발동률 상승 합은 115→160으로 바뀐다. 일반 카나데의 100콤보 SP 조건 충족을 가정한 값이다. 카드별 올림 후보의 SP 원시값은 `71.1 × (51.34 + 160/20) / 100 = 42.19074 → 42.2%`다. 라덴 라이프 조건 충족과 보드 제외 액티브·SP 계산은 기존 기준을 따른다.

패시브 1.5%는 정확한 식에서 산출한 예측이 아니다. **고정된 리더에서 패시브 수혜자 두 명과 그 스킬만으로 표시값이 결정된다면, 수혜자가 아닌 멤버를 바꿔도 유지된다**는 가설이다. 값이 달라지면 추가 편성 맥락이 필요하다는 뜻이다.

이번 카드 교체는 액티브·SP·종합력 패시브와 멤버 보드도 함께 바꾼다. 따라서 패시브가 바뀌어도 액티브만을 원인으로 단정하지 않는다. 보드 표시 6.9%는 AA의 유지 가설로 사용하지 않으며 별도 측정값을 받는다. 우선 멤버 파라미터와 액티브·SP·패시브·보드를 기록하고, 종합력 세부값과 총합이 제공되면 함께 검산한다. 생략된 값은 미기재로 남긴다.
