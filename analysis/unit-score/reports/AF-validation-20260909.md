# AF 검증 — 후레아 서포트 8%와 다음 노엘 서포트 9% AG

기록일: 2026-09-09. 사용자의 최초 입력은 **“홀로멤 2.3%, 패시브 1.0%”**다. 이후 멤버 파라미터 102,771·패시브 종합력 16,443·액티브 71.8%·SP 42.6%도 모두 사전예측과 같은지 물었고, **“네, 모두 일치”**라는 답변을 받았다. 두 메시지를 함께 저장했다. 레벨·개화와 악곡 선택 전 화면은 AF 계획을 이어받은 조건으로, 별도로 재확인된 것으로 기록하지 않았다.

## 1. AF 확인 결과

리더는 수영복 스이세이 60/0. 멤버는 아야메 40/0, 토와 70/0, 수영복 라덴 70/1, 수영복 후레아 80/1, 일반 카나데 80/0이다. 표기는 레벨/개화다.

| 항목 | 고정 사전예측 | 실측/확인값 |
|---|---:|---:|
| 멤버 파라미터 | 102,771 | 102,771 |
| 패시브 종합력 | 16,443 | 16,443 |
| 액티브 | 71.8% | 71.8% |
| SP | 42.6% | 42.6% |
| 홀로멤보드 | 개별 예측 없음 | 2.3% |
| 패시브 스코어 | 개별 예측 없음 | 1.0% |
| 보드+패시브 합계 | 조건부 후보 3.3% 또는 3.4% | 3.3% |

네 가지 기본 항목은 모두 일치한다. 보드와 패시브의 개별 예측은 애초에 `null`이었다. 3.3% 합계는 사전에 제시한 조건부 후보군에 들어가지만, 두 항목의 계산식이 맞았다는 뜻은 아니다.

전체 종합력과 총 스코어보너스는 제공되지 않았다. 119,214는 멤버+패시브 종합력의 계산 소계이며, 117.7%는 확인된 네 스코어 항목의 계산 합이다. 두 숫자를 전체 실측값으로 저장하지 않았다. 의상 종합력 0 역시 조건이 꺼진다는 모형의 추정으로 구분한다.

## 2. 이번 결과로 좁혀진 범위

AF에는 Happy가 라덴·후레아 두 명뿐이므로, 후레아의 서포트 8% 대상이 두 카드로 좁혀진다. AC에서 일반 후레아 11/0만 수영복 후레아 80/1로 교체한 구성이므로 멤버 캐릭터와 입력된 발동률·발동 빈도 보드는 같다.

| 항목 | AC | AF |
|---|---:|---:|
| 액티브 | 68.4% | 71.8% |
| SP | 40.7% | 42.6% |
| 홀로멤보드 | 1.5% | 2.3% |
| 패시브 스코어 | 항목 없음 | 1.0% |

그러나 후레아 교체는 액티브·SP·파라미터·종합력 패시브도 바꾼다. 따라서 보드의 +0.8%p를 서포트 패시브만의 영향이라고 단정할 수 없다. 보드 해금 상태가 같아도 카드 스킬 구성이 달라지면 보드 표시값이 달라질 수 있다는 대조다.

현재 합계 모형의 AF 원시 계산은 다음과 같다.

- 보드 제외 액티브 `Araw = 71.726666…`
- 보드만 반영 `Braw = 72.312886…`
- 보드와 대상별 서포트를 함께 반영 `BPraw = 74.990069…`
- 원시 합계 증가분 `BPraw − Araw = 3.263402…`

마지막 증가분이 실제 두 항목의 원시 합이며 각 항목을 따로 소수 첫째 자리까지 올린다고 가정하면, 표시 합계는 3.3% 또는 3.4%가 가능하다. AF 3.3%는 이 **미확정 모형군의 첫 후속 사전 검증**에 들어맞는다. 이전 14건은 후보군을 정리할 때 이미 있던 사후 대조다. 양의 서포트 패시브 15건의 합계가 모두 이 범위와 호환된다는 사실과, 개별 항목을 계산할 수 있다는 주장은 구분한다.

보드와 패시브를 단순한 누적 증가분으로 나누면 `72.4 − 71.8 = 0.6%`, `75.0 − 72.4 = 2.6%`가 된다. 실측 2.3% / 1.0%와 다르며, 이 배정식은 이전 편성에서도 실패했다. AF의 0.6% / 2.6%는 계획에 진단 참고값으로만 남겼고 채택한 예측으로 제시하지 않았다.

## 3. 추가로 대조한 단순 패시브 후보

Z/AA/AB/AF에 대해 보드 포함/제외와 가중 액티브/확률을 고려한 최댓값 방식의 네 조합을 대조했다. 각 조합에서 원시 증가량 올림과 두 누적 표시값 차감도 비교했지만 네 편성의 패시브 실측을 재현하지 못했다. 최댓값 방식은 액티브 기본식으로 채택하지 않은 진단용 대안이다.

| 편성 | 실측 패시브 | 보드 포함 가중 모형의 원시 패시브 증가분 |
|---|---:|---:|
| Z | 1.5% | 2.902875… |
| AA | 0.8% | 2.749467… |
| AB | 1.8% | 2.953017… |
| AF | 1.0% | 2.677182… |

이 원시 증가분에 공통 상수 하나를 곱한 뒤 올리는 방식도 네 실측을 동시에 만족하지 못한다. 예를 들어 AA가 허용하는 상수는 약 0.255 초과~0.291 이하인 반면 AF는 약 0.336 초과~0.374 이하로 겹치지 않는다. 정확한 구간은 JSON 결과에 저장했다. 임의의 편성별 보정 상수는 추가하지 않았다.

따라서 현재 결론은 **보드와 서포트 패시브를 함께 반영한 합계 모형은 후보로 유지하되, 개별 항목 배정은 미확정**이다. 패시브가 없는 스이세이 리더 AC/AD/AE에서 확인한 보드 표시값 차감식을 양의 서포트 패시브 상황에 그대로 확장하지 않는다. 리리카 보드 확장 대조의 G 13.7% 예측 대 13.8% 실측 차이와 아야메 스코어 서포트 의상 계산도 계속 미해결이다.

## 4. 다음 AG — 노엘의 3기생 서포트 9%

현재 AF에서 두 장을 바꾼다.

- 수영복 후레아 80/1 → **일반 후레아 11/0**
- 일반 카나데 80/0 → **수영복 노엘 80/1**

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 수영복 스이세이 | 60/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 수영복 라덴 | 70/1 |
| 멤버 | 일반 후레아 「하프 엘프의 바람이 스치는 곤돌라」 | 11/0 |
| 멤버 | 수영복 노엘 | 80/1 |

AC를 기준으로는 일반 카나데만 수영복 노엘로 교체한 편성이다. 3기생은 노엘·일반 후레아 둘뿐이고, 양의 스코어 서포트 패시브 제공자는 노엘 하나다. 노엘의 9% 서포트가 이 두 카드에 적용되는 구성을 검증한다. 와타메·수영복 후레아의 8% 서포트는 없다. 종합력에 작용하는 다른 패시브는 별도로 남아 있다.

| AG 항목 | 고정 사전예측 |
|---|---:|
| 멤버 파라미터 | 86,545 |
| 의상 종합력 | 0 (조건 꺼짐) |
| 패시브 종합력 | 10,772 |
| 위 세 항목 소계 | 97,317 |
| 액티브 | 74.6% |
| SP | 44.3% |
| 홀로멤보드 | 개별 예측 없음 — 실측 필요 |
| 패시브 스코어 | 개별 예측 없음 — 실측 필요 |

노엘의 3기생 조건부 SP 발동률 40%도 활성화한다. AG의 SP 서포트 합과 발동률 합은 AF와 같고, 기본 모형은 액티브 표시값 74.6%에서 SP 44.3%를 계산한다. 스코어 서포트 패시브와 멤버 보드는 기본 액티브·SP 계산에 넣지 않는다.

조건부 합계 모형군은 AG의 보드+패시브를 **7.0% 또는 7.1%**로 제시한다. 원시 증가분은 `6.908198…`이다. 이것은 미확정 모형을 가정한 합계 후보이며, 정확한 합계 공식이나 개별 항목 예측이 아니다. 기존에 실패한 단순 배정식의 보드 4.0% / 패시브 2.9%는 JSON에 진단 참고값으로만 보관한다.

같은 악곡 선택 전 편성 상세 화면을 사용하고 성장·보드 해금 상태를 유지한다. 일반 후레아는 P에서 확인한 11/0이다. 리더 스이세이의 관련 보드 없음·의상 조건 꺼짐, 아야메의 가창자 조건 제외를 유지한다. 라덴 라이프 600과 일반 후레아 콤보 40 조건은 기존 기본 모형의 충족 가정을 유지한다.

이 교체는 스코어 서포트의 제공자·대상·조건뿐 아니라 카드 스킬과 멤버 보드 맥락도 바꾸므로, 8%에서 9%로 바뀌는 비율만 분리한 실험은 아니다. 두 명의 대상이 명확한 다른 종류의 서포트에서도 모형이 일반화되는지 확인하는 목적이다.

다음 입력은 멤버 파라미터·패시브 종합력·액티브·SP와 **홀로멤보드·패시브 스코어보너스 각각의 값**이다. 총 스코어보너스가 있으면 별도로 검산한다.

## 5. 기록 및 재현

기본 액티브·카드별 SP 서포트 올림 모형은 30개 관측, 20개 서로 다른 멤버 조합을 재현한다. 발견 당시 사후 대조 20건과 이후 검증 10건을 구분하며, 후속 10건 중 새 멤버 조합은 W/AA/AB/AC/AD/AF 여섯 건이다. X/Y/Z/AE는 같은 멤버의 리더 변경 대조다.

- 원문과 추가 확인: `observations/AF-20260909.json`
- 계산 및 대조: `reports/AF-comparison-20260909.json`
- 사전 고정 AG: `experiments/baseline-passive-AG-20260909.json`
- 분석 소스: `compare-passive-af-20260909.mjs`
- 프로젝트 루트에서 재현: `node analysis/unit-score/compare-passive-af-20260909.mjs`

원시 관측·보드 근거·이전 체크포인트·분석 소스의 SHA-256을 검증하고 AG 계획에 기록했다. 기존 예측과 실패 기록, 누락된 전체 수치, Z의 최초 부분 관측과 별도 보완 기록을 보존했다. 서비스용 계산식과 기존 원시 모형 소스는 변경하지 않았다.
