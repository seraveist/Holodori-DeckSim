# AO — 같은 편성에서 카나데 발동률 보드 해제

사용자는 해금한 발동률·빈도 보드를 비용 없이 해제할 수 있다고 확인했다. [AO 사전 계획](../experiments/baseline-board-AO-20260909.json)을 고정한 뒤, AN과 같은 편성에서 카나데 발동률15%·5%만 끄도록 요청했다. 답변은 **“보드 9.4 패시브 1.7”**이다.

| 항목 | AN 실측 | AO 사전 가설 | AO 실측 |
|---|---:|---:|---:|
| 패시브 | 1.6% | 보드 영향 가설1.7% / 불변 가설1.6% | 1.7% |
| 홀로멤 보드 | 10.1% | 전자9.4% / 후자 조건부9.5~9.6% | 9.4% |
| 두 표시값의 합 | 11.7% | 11.1% 또는11.2% | 11.1% |

보드 영향 가설과 일치하고, 이번 변경에 대한 패시브 불변 가설은 탈락했다. 요청한 조건이 유지됐다면 카드와SP를 바꾸지 않은 대조이므로 **발동률 보드가 패시브 표시 배분에 간접 영향을 준다**는 근거다. AM과 같은 표시값으로 돌아왔지만, 모든 SP 독립성이나 개별 배분 공식 전체를 증명하지는 않는다.

액티브·SP·종합력·총 보너스·최종 유닛스코어는 이번 답변에서 제공되지 않았다. 예측을 실측으로 채우지 않는다. 레벨·다른 보드·악곡 선택 상태는 요청 계획에서 상속하며 따로 재확인됐다고 기록하지 않는다. [원문](../observations/AO-20260909.json)에는 카나데 보드 덮어쓰기를 관측별로 남겨 과거 보드 입력을 바꾸지 않았다.

누적39건·멤버 조합23개, 값이 제공된 액티브/SP37/37, 기본 종합력 세부97개, 양의 패시브 합계 후보 호환24건이다. AK와AO는 두 스코어 항목만 확인한 부분 관측이다. 보드 영향 대조의 성공과 아래 새 배분식의 성공 횟수를 혼동하지 않는다.

## 새 배분 후보

[비례 배분 탐색](proportional-allocation-AO-20260909.json)은 총 증가분을 효과의 계산상 비중으로 나눈다.

- 카드별 가중치: `발동확률 × 액티브 효과량 × 지속시간 × floor(200 / 기본 발동주기)`.
- 패시브 비중 PW: 가중치×각 수혜자의 패시브 서포트% 합.
- 보드 비중 BW: 가중치×`100×[(1+발동률%/100)(1+빈도%/100)(1+리더 서포트%/100)−1]` 합.
- 기존 원시 합계 S를 `S×PW/(PW+BW)`와 `S×BW/(PW+BW)`로 나눈 뒤 각각0.1 단위 올림.

이 식은 AO까지 양의 패시브24건 중 **20건에서 두 항목을 동시에 재현**한다. 각 항목은22/24다. 하지만 전부 과거 실측을 본 뒤 찾은 결과다. AO의 보드 대조는 사전 가설 검증이지만, 이 새 비례식의 독립 검증으로 세지 않는다.

| 남은 실패 | 패시브 예측 / 실측 | 보드 예측 / 실측 |
|---|---:|---:|
| W | 1.9 / 1.9 | 17.2 / 17.3 |
| AA | 0.9 / 0.8 | 3.3 / 3.3 |
| AF | 1.0 / 1.0 | 2.4 / 2.3 |
| AH | 2.1 / 2.2 | 15.3 / 15.3 |

168개 가중치·효과 조합을 비교했다. 배분 가중치의 기간도30~600, 세 가지 횟수 처리로1,713개 조합을 탐색했지만 전부 맞는 식은 없다. 405라는 사후 선택값은23/24까지 맞아도 AF가 남는다. 이를 실제 내부 길이로 채택하거나 서비스에 적용하지 않았다. 기존 액티브 모형의200을 쓰는 더 단순한 후보를 후속 검증 대상으로 고정했다.

## AP 사전 검증

AO 편성에서 **카나데15%·5%는 계속 OFF**, **노엘 발동빈도4%만 추가 OFF**. 노엘 발동률 합23.5%, 후레아6%, 리리카 리더 보드는 유지한다.

| 항목 | AP 사전 예측 |
|---|---:|
| 멤버 / 의상 / 패시브 종합력 | 79,007 / 11,859 / 7,816 |
| 액티브 / SP | 75.2% / 43.9% |
| 패시브 / 보드 | **2.3% / 12.1%** |
| 두 표시값 합계 후보 | 14.4% 또는14.5% |

빈도를 낮췄는데 합계가 오르는 예측이다. 현재200초 모형에서는 액티브 구간의 겹침이 달라지기 때문이다. 실제 악곡 점수가 좋아진다는 주장으로 해석하지 않는다. 이 대조는 새 비례 배분뿐 아니라 빈도 변경 후 시간축을 계산하는 기존 합계 모형도 시험한다.

개별값 실패와 합계 실패는 구분해 남긴다. 맞아도 새 비례식의 독립 성공은 처음 한 건이며, 위 네 과거 오차와 G의 보드 오차, 스코어 서포트 의상, 미검증 실제 악곡 점수는 남는다. 서비스 공식은 변경하지 않았다.
