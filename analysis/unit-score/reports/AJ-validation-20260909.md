# AJ 검증 — 두 변환 후보 실패, 같은 리리카의 의상 효과량을 비교하는 AK

기록일: 2026-09-09. AJ 사용자 원문은 **“홀로멤보드 12.2%, 패시브 1.5% 나머지 일치”**다. 직전 표의 기본 다섯 수치 일치도 확인된 것으로 저장했다. 편성·성장·순서·악곡 선택 전 화면은 계획을 이어받으며 별도 재확인으로 기록하지 않는다.

## 1. AJ 결과

리더는 리리카 5성 「심야의 휴식, CEO의 한계밥」 40/0이다. 멤버는 아야메 40/0·토와 70/0·수영복 라덴 70/1·일반 카나데 80/0·수영복 와타메 70/1이다. 표기는 레벨/개화다.

## 2. 두 공통 변환을 이번 편성까지 확장할 수 없음

같은 멤버의 AA→AJ에서는 패시브가 0.8%→1.5%(+0.7%p), 보드가 3.3%→12.2%(+8.9%p)로 변했다. 액티브·SP는 그대로다. 동시에 파라미터 의상도 비활성→활성(50,131)으로 바뀌었다.

이전 Z/W·AG/AH·AB/AI 세 쌍은 의상이 비활성인 리더 비교다. 그 자료가 허용한 원시값 배율은 `1.235294… < k < 1.294117…`, 가산량은 `0.4 < d < 0.5`였다. 반면 AA/AJ 표시값만으로도 배율은 `1.75 < k < 2.142857…`, 가산량은 `0.6 < d < 0.8`이 필요하다. 네 쌍을 모두 만족하는 공통 구간이 없다.

따라서 **파라미터 의상이 스코어에 영향을 주지 않는다는 가정 아래 만든 두 AJ 예측은 모두 실패**했다. 이전 세 쌍의 제한된 범위가 자체적으로 틀렸다는 뜻은 아니다. 이번에는 리더 캐릭터/보드와 의상 활성 상태가 함께 바뀌었으므로, 실패의 원인을 의상으로만 단정하지 않는다. 멤버 구성에 따른 리더 효과 변화도 남는 가능성이다. 새 공통 계수를 임의로 덧붙이지 않는다.

합계 13.7%의 호환성은 유지됐다. 이는 원시 합계 모형과 두 항목 각각의 올림을 가정한 후보군 검증이며, 패시브·보드 개별 계산식의 성공을 뜻하지 않는다.

## 3. 다음 AK — 리리카 캐릭터와 보드를 유지한 의상 효과량 비교

사용자가 리리카 3성 「We are hololive!」를 **보유 중이며 1레벨·0개화**라고 확인했다. 별도 프로필 근거로 저장했다.

현재 AJ에서 **리더 카드만 리리카 3성 「We are hololive!」 1/0으로 바꾼다.** 멤버·성장·순서·보드 해금 상태를 유지한다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 리리카 3성 「We are hololive!」 | 1/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 수영복 라덴 | 70/1 |
| 멤버 | 일반 카나데 「퍼레이드로 미소를 전달」 | 80/0 |
| 멤버 | 수영복 와타메 | 70/1 |

리리카 5성의 RegLOSS 2명 조건 전원 파라미터 50% 효과에서, 3성의 무조건 전원 파라미터 15% 효과로 바뀐다. 두 카드 모두 스코어 서포트 의상 효과는 없다. 동일한 리리카 캐릭터이므로 기록된 리더 보드 입력을 고정한다. 무조건 서포트 13.3%는 유지하고, 판정 보정 노드의 수치 기여는 여전히 미확정이며, 가창자 조건 24%는 악곡 선택 전 비교에서 제외한다.

| AK 항목 | 사전예측/검증 가설 |
|---|---:|
| 멤버 파라미터 | 100,252 |
| 의상 종합력 | **15,047** |
| 패시브 종합력 | 22,531 |
| 위 세 항목 소계 | 137,830 — 전체 종합력 아님 |
| 액티브 | 71.1% |
| SP | 42.2% |
| 패시브 스코어 | **1.5% 유지 가설** |
| 홀로멤보드 | **12.2% 유지 가설** |
| 보드+패시브 합계 | 조건부 13.7% / 13.8% |

의상 종합력은 AJ 대비 35,084 감소한다. 액티브·SP는 기존 보드 제외 계산식을 사용한다. 패시브 1.5%와 보드 12.2%는 AJ 실측을 기준으로 한 **이번 교체에서의 유지 가설**이며, 카드만으로 산출하는 일반 공식이 아니다. 원시 합계 입력은 AJ와 같아 조건부 합계 후보도 유지된다.

- 두 스코어 항목이 같으면: 이 편성에서 파라미터 의상 50%→15% 및 리더 카드 변경에 따른 불변성을 지지한다. 멤버 구성에 따른 리더 효과 차이를 다음 조사 방향으로 삼을 수 있다.
- 어느 항목이 달라지면: 같은 멤버·리리카 보드 아래에서도 리더 카드/의상 맥락에 의존함을 보여 준다. 변화만으로 특정 의상 계산식을 확정하지 않는다.

**두 의상 모두 활성 상태**이므로 결과가 같아도 의상 활성 여부에 따른 상호작용은 배제할 수 없다. 또한 리더 카드의 성장과 멤버용 스킬도 다르다. 현재 모형은 리더 슬롯에서 멤버용 스킬을 제외하므로, 변화가 생기면 이 가정까지 점검해야 한다. 같은 악곡 선택 전 화면을 사용하고, 일반 카나데 콤보 100·라덴 라이프 600 충족은 기존 계산 가정으로 유지한다.

다음 입력은 **패시브 스코어와 홀로멤보드 각각의 값**, 그리고 기본 다섯 값(멤버·의상·패시브 종합력·액티브·SP)의 일치 여부다. 전체 총합은 제공되는 경우에만 실측으로 추가한다.

## 4. 누적 검증과 재현

AJ까지 기본 액티브·SP는 **34개 관측 / 21개 서로 다른 멤버 조합**을 모두 재현한다. 발견 시 사후 대조 20건, 이후 새 멤버 조합 7건, 같은 멤버의 리더 변경 7건이다. 미측정 AK는 세지 않는다.

양의 서포트 패시브가 있는 관측 중 조건부 합계 후보군에 호환되는 자료는 **19건**이다. 사후 14건과 후속 사전 검증 AF/AG/AH/AI/AJ 5건을 구분한다. 단순한 개별 보드 효과량 계산은 이 19건에서 모두 실패하므로 합계 호환성을 개별 공식 확정으로 확대하지 않는다. 무패시브 보드 대조는 기존 상태를 유지하며 G의 0.1%p 잔차, 리리카 판정 보정의 기여, 아야메 스코어 서포트 의상 계산식도 미해결이다.
