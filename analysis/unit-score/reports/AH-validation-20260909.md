# AH 검증 — 의상 효과가 꺼진 리더 비교와 AI의 패시브 2.3% 가설

기록일: 2026-09-09. 사용자 원문은 **“홀로멤 보드 15.3%, 패시브 2.2%, 나머지 일치”**다. 직전 AH 예측 표의 멤버 파라미터·패시브 종합력·액티브·SP도 일치한 것으로 저장했다. 편성·성장·배치 순서·악곡 선택 전 화면은 계획을 이어받은 조건이며, 별도 확인을 받은 것으로 기록하지 않았다.

## 1. AH 확인 결과와 AG 비교

AH는 리리카 40/0 리더, 아야메 40/0·토와 70/0·수영복 라덴 70/1·일반 후레아 11/0·수영복 노엘 80/1 멤버다. 표기는 레벨/개화다. AG에서 리더만 수영복 스이세이 60/0에서 리리카로 바꿨다.

| 항목 | AG: 스이세이 리더 | AH: 리리카 리더 | 변화 |
|---|---:|---:|---:|
| 멤버 파라미터 | 86,545 | 86,545 | 0 |
| 패시브 종합력 | 10,772 | 10,772 | 0 |
| 액티브 | 74.6% | 74.6% | 0 |
| SP | 44.3% | 44.3% | 0 |
| 홀로멤보드 | 5.3% | 15.3% | +10.0%p |
| 패시브 스코어 | 1.7% | 2.2% | +0.5%p |
| 보드+패시브 합계 | 7.0% | 17.5% | +10.5%p |

네 기본 항목은 모두 사전예측과 맞는다. AH 합계 17.5%도 사전에 고정한 조건부 17.4% / 17.5% 후보군에 들어간다. 개별 보드·패시브 수치는 사전에 예측하지 않았다. 기존에 실패한 단순 배분의 보드 14.4% / 패시브 3.0%는 이번에도 실측과 다르다.

전체 종합력·총 스코어보너스는 미제공이다. 97,317은 멤버+패시브 종합력의 계산 소계이고, 136.4%는 확인된 스코어 항목의 계산 합이다. 전체 실측값으로 저장하지 않았다. 의상 종합력도 원시 관측은 `null`이고, 발동 조건에 따른 0 추정과 구분한다.

AG와 AH 모두 의상 발동 조건은 꺼져 있다. AH에는 RegLOSS 멤버가 라덴 한 명뿐이다. 노엘의 서포트 9% 대상, 액티브·SP 조건, 멤버 보드 입력은 그대로다. 따라서 이번 편성에서는 **의상 효과가 꺼져 있어도 리더 변경에 따라 패시브 표시값이 달라짐**을 확인했다. 이것을 아야메 의상 효과의 증거로 사용하지 않는다.

리리카에는 스코어 서포트 합 13.3%뿐 아니라 수치 확률이 미확인인 판정 보정 노드도 있다. 이번 비교로 두 효과 중 어느 것이 관여하는지 분리하지 못한다. 가창자 조건 서포트 24%는 계획된 악곡 선택 전 맥락에서 제외한다.

## 2. 기존 리더 비교와 공통점

| 같은 멤버끼리의 비교 | 스이세이 패시브 | 리리카 패시브 | 표시 차이 |
|---|---:|---:|---:|
| Z → W: 와타메 서포트 8% | 1.5% | 1.9% | +0.4%p |
| AG → AH: 노엘 서포트 9% | 1.7% | 2.2% | +0.5%p |

둘 다 의상 조건이 꺼진 리더 비교다. 표시값에 같은 고정량을 더하는 방식은 두 차이를 동시에 설명하지 못한다. 패시브 표시값에 리리카 보드 13.3%를 한 번 곱한 뒤 올리면 각각 1.7%와 2.0%여서 실측 1.9%와 2.2%에 미달한다.

표시값이 원시 패시브의 올림이라고 가정해 숨은 소수값까지 허용해도, 단순 1.133배는 첫 쌍에서 1.6% 또는 1.7%, 둘째 쌍에서 1.9% 또는 2.0%만 낼 수 있다. 이는 13.3% 노드가 원인이 아니라는 뜻이 아니라, **패시브에 13.3%를 단순히 한 번 곱하는 식이 맞지 않는다**는 뜻이다.

## 3. 새 가설: 실측 패시브 표시값을 이용한 리더 변환

AH를 받은 뒤 다음 경험적 후보군을 만들었다.

`리리카 패시브 표시값 = 소수 첫째 자리까지 올림(k × 스이세이 패시브 표시값)`

두 쌍을 동시에 만족하는 배율 구간은 다음과 같다.

**1.2352941176… < k ≤ 1.2666666667…**

이는 두 쌍의 결과를 받은 뒤 찾은 사후 후보군이다. 1.25와 1.266을 포함해 여러 값이 가능하므로 특정 배율을 확정하지 않는다. 특히 1.266을 보고 `1 + 2 × 13.3%`가 내부 공식이라고 해석하지 않는다.

이 가설의 입력은 **이미 실측한 스이세이 리더의 패시브 표시값**이다. 멤버 카드만으로 기본 패시브를 계산하는 공식은 아직 없다. 이전에 실패한 ‘보드 반영 원시 패시브 증가분에 공통 상수를 곱하는 방식’과도 다른 가설이며, 이전 실패 기록은 유지한다.

현재 자료에는 다른 설명도 가능하다. 숨은 원시 패시브를 입력으로 한 공통 배율이나 공통 가산량도 두 쌍을 맞출 수 있다. 따라서 다음 AI가 2.3%여도 이 경험적 변환식 하나로 확정할 수 없다. 새 값이 2.3%가 아니면 이번 **표시값 입력 공통 배율 후보군**은 탈락시킨다.

## 4. 다음 AI — 기존 AB와 리더만 다른 편성

현재 AH에서 **수영복 노엘 80/1만 수영복 와타메 70/1로 교체**한다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 리리카 | 40/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 수영복 라덴 | 70/1 |
| 멤버 | 일반 후레아 「하프 엘프의 바람이 스치는 곤돌라」 | 11/0 |
| 멤버 | 수영복 와타메 | 70/1 |

AI의 대조 기준은 **AB**다. AB와 멤버·성장·멤버 보드·배치 순서는 같고, 리더만 스이세이에서 리리카로 달라진다. 두 편성 모두 의상 조건은 꺼져 있고, Happy인 라덴·와타메 둘이 서포트 8% 대상이다. AH와 AI를 비교하면 멤버도 바뀌므로, 리더 영향은 AB와 AI를 비교해 판단한다.

| AI 항목 | 고정 사전예측 | 근거 상태 |
|---|---:|---|
| 멤버 파라미터 | 84,026 | 기존 기본 계산 |
| 의상 종합력 | 0 | 발동 조건 꺼짐 |
| 패시브 종합력 | 13,617 | 기존 기본 계산 |
| 위 세 항목 소계 | 97,643 | 전체 종합력 아님 |
| 액티브 | 73.7% | 기존 보드 제외 계산 |
| SP | 43.6% | 기존 보드 제외 계산 |
| 패시브 스코어 | **2.3%** | **새 경험적 변환 후보군의 첫 후속 검증** |
| 보드+패시브 합계 | 17.8% 또는 17.9% | 기존 조건부 합계 후보군 |
| 홀로멤보드 | 15.5% 또는 15.6% | 위 패시브·합계 가설이 모두 맞을 때만 가능한 값 |

AB의 실측 패시브는 1.8%다. 새 배율 구간의 어떤 값을 곱해도 결과는 `2.223529… 초과 ~ 2.28 이하`이므로, 올림 표시값은 **2.3% 하나로 좁혀진다**. 편성별 상수나 특정 배율을 고르지 않고 내는 예측이다.

반면 원시값을 입력으로 한 다른 모형군은 AI에서 다음 값들도 허용한다.

- 원시 패시브에 공통 가산량을 더하는 후보군: 2.2% 또는 2.3%
- 원시 패시브에 공통 배율을 곱하는 후보군: 2.2%, 2.3%, 2.4% 또는 2.5%

따라서 AI 2.3%는 새 표시값 변환 가설의 첫 사전 예측 성공이 될 수 있지만, 다른 후보를 모두 배제하지는 않는다. 이 대안 구간도 AH 시점에 고정했다.

기존 합계 모형의 AI 원시 증가분은 `17.756757…`다. 별도 올림을 가정한 합계 17.8% / 17.9%에서 패시브 가설 2.3%를 빼면 보드 15.5% / 15.6%가 된다. **독립적인 보드 공식으로 계산한 값은 아니다.** 과거에 실패한 단순 배분의 보드 14.8% / 패시브 3.0%는 진단 참고값으로만 남겼다.

같은 악곡 선택 전 편성 상세 화면을 사용하고, 멤버 보드 해금·성장·배치를 유지한다. 아야메 가창자 조건은 제외하고 라덴 라이프 600·일반 후레아 콤보 40은 기존 기본 모형의 충족 가정을 유지한다. 리리카의 판정 보정 기여, G의 0.1%p 잔차, 아야메 스코어 서포트 의상 식은 계속 미확정이다.

다음에는 위 기본 수치와 **홀로멤보드·패시브 스코어 각각의 값**을 확인한다. 총 스코어보너스가 있으면 별도로 검산한다.

## 5. 누적 검증과 파일

기본 액티브·SP는 32개 관측, 21개 서로 다른 멤버 조합을 재현한다. AH는 AG와 같은 멤버여서 새 멤버 조합으로 세지 않는다. 모형 발견 당시 사후 대조 20건, 이후 새 멤버 조합 7건과 같은 멤버의 리더 변경 5건이다.

양의 서포트 패시브 합계 후보군에 호환되는 관측은 17건으로, 사후 대조 14건과 후속 사전 검증 AF/AG/AH 3건을 구분한다. 단순 개별 배분식은 17건 모두 보드값이 맞지 않는다.
