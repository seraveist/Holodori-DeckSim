# X 검증과 리더 보드 재확인 — 2026-09-09

X의 종합력 세부값·액티브 75.5%·SP 43.2%는 사전 예측과 일치했다. 패시브는 예상했던 유지값 1.9%와 달리 **1.5%**이므로 해당 가설은 실패다. 사용자가 카나데의 관련 리더 보드 효과가 없고, W/X 모두 악곡 선택 전 편성 상세 화면임을 확인했다.

W→X는 리리카에서 카나데로 리더 캐릭터까지 바꾼 비교다. 따라서 의상과 함께 리더 보드도 달라졌다. 앞서 이를 종합력 의상만 바꾸는 대조로 설명한 부분을 정정하며, 패시브 감소를 의상 효과로 단정하지 않는다. 다음 Y는 같은 카나데 캐릭터 안에서 의상만 비교한다.

## X 실측과 예측

수영복 카나데 40/0 리더에 아야메 40/0·토와 70/0·라덴 70/1·수영복 노엘 80/1·수영복 와타메 70/1을 사용하는 X 계획에 대한 응답으로 기록했다. 카드 성장값을 별도로 재확인한 것으로 처리하지 않았다.

| 항목 | 사전 예측 | 실측 |
|---|---:|---:|
| 멤버 파라미터 | 100,252 | 100,252 |
| 의상 종합력 | 43,945 | 43,945 |
| 패시브 종합력 | 12,584 | 12,584 |
| 위 세 항목 합 | 156,781 | 156,781 |
| 액티브 | 75.5% | 75.5% |
| SP | 43.2% | 43.2% |
| 패시브 스코어 보너스 유지 가설 | 1.9% | **1.5%** |

전체 종합력 **177,959**에서 비교한 세 항목을 빼면 **21,178**이다. 보드·메모리·강화의 개별 수치는 미제공이므로 임의 배분하지 않았다. 스코어 보너스 합은 **75.5 + 6.9 + 1.5 + 43.2 = 127.1%**다. 의상 스코어 보너스는 미기재 `null`로 보존하며, 별도 측정된 0으로 기록하지 않았다.

액티브와 SP 연구 후보는 각각 **22건·서로 다른 멤버 조합 15개**를 재현한다. SP 카드별 올림 기준으로는 발견 당시 20건의 사후 비교, 새 멤버 조합 W의 구분 검증, 같은 멤버의 리더 교체 X 추가 확인이다. 22개의 독립 사전 예측 성공으로 세지 않는다. 서비스 계산식은 변경하지 않았다.

## W→X에서 바뀐 값

| 항목 | W: 리리카 | X: 수영복 카나데 | 변화 |

| SP | 43.2% | 43.2% | 0%p |

다섯 멤버와 현재 구현상 와타메·라덴 각 8% 패시브 서포트는 그대로다. 반면 종합력 의상은 리리카 조건 불충족에서 카나데 퍼포먼스 130% 적용으로 바뀌고, 리더 보드도 함께 바뀐다. 표시 보드 항목을 빼도 패시브 차이 0.4%p가 남지만, 이것만으로 보드가 패시브 계산과 독립이라는 결론을 낼 수 없다.

이 비교는 패시브의 리더 관련 조건을 더 확인해야 한다는 근거다. **종합력 의상 변화, 리더 보드 상호작용, 그 밖의 리더별 기여 배분 중 무엇이 원인인지는 아직 분리되지 않았다.** 패시브 1.9% 유지 예측과 실패 결과를 원본 그대로 남겼으며 이후 설명으로 사전 가설을 소급 변경하지 않았다.

## 사용자가 확인한 리더 보드와 화면

| 리리카 리더 보드 | 이번 확인 내용 | 분석 처리 |
|---|---|---|
| 스코어 서포트 | 4.0%, 6.2%, 3.1% | 산술합 **13.3%**, 기존 기록과 일치 |
| 판정 보정 | 20초마다 낮은 확률, 7초간 GOOD 이상을 PERFECT로 | 확률 수치와 편성 상세에서의 기여 방식은 미확정 |
| 가창자 조건 서포트 | 악곡 가창자에 포함되면 전원 24.0% | 조건부 노드로 보관, 무조건 합산하지 않음 |

사용자는 위 내용이 종합력을 제외하고 스코어 보너스에 영향을 줄 수 있는 리리카의 모든 노드라고 명시했다. 기존 `board-context.json`에는 서포트 세 노드가 6.2, 4, 3.1 순으로 이미 있었다. 판정 보정과 가창자 조건 24%는 기존 입력에 없던 추가 정보다. 이번에 새로 기록됐다는 사실을 이번에 해금하거나 효과가 바뀌었다는 뜻으로 해석하지 않는다.

후속 답변은 다음과 같이 보존했다.

- 카나데 관련 리더 보드: **“카나데는 리더효과 없음.”** 질문의 범위가 리더 보드이므로, 이 답변은 카나데 의상의 퍼포먼스 130% 효과나 과거 카나데 멤버 발동률 보드 15%·5%를 부정하는 뜻이 아니다.
- W/X 측정 화면: **“둘 다 악곡 선택 전 편성 상세.”** 실제 선택 악곡에 대한 가창자 조건이 확인된 상태가 아니다.

따라서 가창자 24%를 기본 계산에 항상 넣지 않는다. 악곡 미선택 편성 화면의 내부 평가가 해당 조건을 어떻게 처리하는지는 별도 확인 사항이다. 또한 낮은 확률을 임의의 숫자로 바꾸거나, 판정 보정이 화면 보너스에 전혀 기여하지 않는다고 확정하지 않는다.

서포트 입력 합 13.3%와 실측 보드 보너스 차이 10.4%p는 서로 다른 값이다. 13.3을 보드 표시값에 그대로 더하거나, 24를 더한 37.3%를 무조건 전원 서포트로 적용하지 않는다. 카나데 리더 보드가 없어도 X의 보드 표시가 6.9%인 것은 리더 보드와 전체 편성의 보드 표시가 같은 범위가 아님을 보여준다. 그 6.9%의 개별 원인 배분은 미확정이다.

이전의 보드 제외는 기본 연구식의 작업 가정이었다. 기본 액티브·SP의 보드 제외 계산과 과거 예측은 유지한다. **패시브 분석에서는 리더 보드의 상호작용 가능성을 별도 가설로 다시 검증**한다. 이번 자료만으로 전체 보드를 카드 스킬 계산에 추가하거나 서비스 공식을 수정하지 않았다.

## 다음 Y: 같은 카나데의 의상 비교

X의 다섯 멤버와 성장값을 유지하고, 리더를 **수영복 카나데 40/0 → 일반 카나데 「퍼레이드로 미소를 전달」 80/0**으로 교체한다. 같은 악곡 선택 전 편성 상세 화면에서 확인한다.

| 멤버 | 수영복 와타메 | 70/1 |

카나데 캐릭터와 관련 리더 보드 없음은 유지된다. 의상은 Happy 2명 조건의 퍼포먼스 130%에서 Pure 2명 조건의 센스 130%로 바뀐다. Y의 Pure 멤버는 아야메·토와이므로 조건은 충족한다. 리더 카드의 액티브·SP·패시브 멤버 스킬은 계산에 넣지 않는다.

| Y 사전 검산·가설 | 값 |
|---|---:|

| 의상 종합력 | **49,934** |
| 패시브 종합력 | 12,584 |
| 위 세 항목 합 | 162,770 |
| 액티브 후보 | 75.5% |
| SP 후보 | 43.2% |

패시브와 보드의 유지값은 확정 공식에서 계산한 값이 아닌 대조 가설이다. Y에서도 패시브 1.5%가 유지되면 이 퍼포먼스→센스 의상 교체에는 패시브가 변하지 않았다는 근거가 되고, W/X의 리더 보드·캐릭터 차이를 우선 확인할 이유가 커진다. 그렇다고 리리카 보드가 정확히 +0.4%p를 만들었다고 증명되는 것은 아니다. 두 의상 모두 종합력 효과가 있으므로 무효 의상과 유효 의상 사이의 모든 차이를 배제하지도 못한다.

Y에서 패시브가 바뀌면 같은 캐릭터·관련 리더 보드 없음 조건에서도 의상 또는 파라미터 분포에 따른 기여 배분이 달라지는지 분석한다. 실측은 종합력 전체/멤버/의상/패시브와 총 보너스/액티브/SP/패시브/보드/의상 표시 여부를 함께 기록한다.
