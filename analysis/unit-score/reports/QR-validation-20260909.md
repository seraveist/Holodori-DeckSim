# Q/R 기본 SP 검증 — 2026-09-09

종합력의 보고된 세부 항목과 액티브 73.3%는 Q/R 모두 사전 계산과 일치한다. SP는 Q 40.5%, R 41.3%로 기존 두 계수 후보보다 각각 0.2%p, 0.1%p 낮다. O/P에서 맞았던 기존 계수를 정확한 기본 공식으로 채택하지 않는다.

보너스 합계는 Q 73.3 + 40.5 + 14.9 = 128.7%, R 73.3 + 41.3 + 15.3 = 129.9%로 일치한다. 보드를 제외하면 **113.8% / 114.6%**다. 미기재 의상·패시브 보너스는 `null`로 보존했으며 정확한 내부 0의 실측이라고 바꾸지 않았다. 제공된 세 항목만으로 표시 총합이 완성되고, 계획의 카드 효과를 계산하면 스코어 서포트 의상·패시브는 모두 0이다.

사용자가 Q/R 편성명으로 수치를 제공했으므로 해당 계획의 카드와 성장값을 비교 입력으로 사용했다. 별도 성장값 재확인 답변을 받은 것으로 기록하지 않았다. 이번에는 제공된 모든 종합력 세부 항목이 그대로 일치한다.

## 이번 비교로 좁힌 것

다섯 액티브의 유효 성능과 200초 후보의 원시 평균 **73.27772900476324**는 Q/R에서 같다. 교체한 SP는 스이세이 **12초·서포트 100%**에서 카나데 **14초·95%**로 바뀌며, 두 SP 모두 발동률 추가 조건은 적용되지 않는다. 나머지 네 SP는 같다. 이때 SP 표시값은 **+0.8%p**다.

서포트×지속시간은 1,200→1,330으로 130 증가한다. 기존 연구 모델의 서포트 기여는 0.4763052385 증가하고, 별도 발동률 기여는 같게 유지된다. 표시 오차 범위를 고려하면 이 차이만으로 서포트 기여 배율은 약 **1.46965~1.88954** 범위가 가능하다. 따라서 지속시간을 가중하는 후보와 부합하지만 정확한 배율이나 두 변수 각각의 독립 법칙을 정하지는 못한다.

리리카의 파라미터 의상 조건 및 파라미터 패시브도 Q/R에서 달라진다. 액티브·SP 스코어 서포트 효과의 비교와 종합력 검산을 구분하며, 의상 종합력 조건이 SP에 어떤 영향도 없다는 사실까지 증명한 것은 아니다. 현재 기본 스킬 분석에서는 사용자 지시에 따라 보드 보정을 제외한다.

## 패시브 없는 G/O/P/Q/R을 함께 분석

다섯 편성은 모두 발동률 **40% 상승 SP 두 개**를 사용한다. 발동률 상승 SP의 개수가 고정되어 있어 그 효과를 분리하는 증거가 부족하다.

연구 모델의 입력을 다음과 같이 정의한다.

- S: 발동률 효과가 있는 상태에서 SP 서포트를 추가한 증가량에 지속시간을 가중한 값. 발동률과 서포트의 동시 적용 효과가 포함된다.
- R: 발동률만 적용한 증가량에 지속시간을 가중한 값.

기존 식 `1.6427794 × S + 2.8630798 × R`은 새 Q/R을 정확히 맞추지 못한다. 반면 다섯 편성의 표시 구간만 조건으로 삼으면 가능한 두 계수 조합이 여러 개 남는다. 원래 여섯 조합 전체에서 두 계수만으로 모든 표시값을 맞추지 못했던 결론과 다른 범위의 분석이다.

특히 `SP = 0.1%p 단위 올림(k × S)`라는 더 단순한 후보도 다섯 값에 맞는다. 가능한 배율은 **1.7273994693 < k ≤ 1.7281226333**이며, 예시 중간값 **1.7277610513**을 다음 실험에 고정했다.

| 편성 | 새 후보 표시값 | 실측 |
|---|---:|---:|
| G | 38.7% | 38.7% |
| O | 37.0% | 37.0% |
| P | 37.5% | 37.5% |
| Q | 40.5% | 40.5% |
| R | 41.3% | 41.3% |

**이는 다섯 실측을 보고 만든 사후 후보이며, 사전 예측 성공이나 게임 공식 확정이 아니다.** 여기서 별도 R 항이 없다고 발동률 효과가 없다는 뜻도 아니다. S 안에 발동률과 서포트의 동시 적용이 이미 포함된다. 올림 규칙 자체도 SP에서 확정되지 않았으며, 다른 표시 방식의 두 계수 가능 영역도 JSON에 보존했다.
