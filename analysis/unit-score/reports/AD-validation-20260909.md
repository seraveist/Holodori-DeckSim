# AD 검증과 보드 버림·표시값 차감 비교 AE — 2026-09-09

AD 실측 보드 **5.3%**는 사전의 버림·액티브 표시값 차감 후보와 일치한다. **원시 증가량 반올림 후보 5.4%는 실패**했다. 이는 현재 시험 중인 원시 보드 계산을 전제로 한 후보 구분이며, 게임의 보편적인 반올림 규칙을 확정한 것은 아니다.

남은 두 후보는 다음 AE에서 **4.8% 대 4.9%**로 갈린다. AE는 AD의 일반 후레아 11/0만 수영복 노엘 80/1로 교체한다. 서비스 계산식과 과거 예측은 보존했다.

## AD 확인 결과

사용자 답변 **“모두 일치, 보드 5.3%”**를 직전 AD 표의 수치 및 패시브 항목 없음에 대한 확인으로 기록했다. 보드 수치는 직접 명시됐다.

| 항목 | 사전 예측 | 확인 결과 |
|---|---:|---:|
| 멤버 파라미터 | 76,437 | 76,437 |
| 패시브 종합력 | 12,553 | 12,553 |
| 액티브 | 71.3% | 71.3% |
| SP | 41.6% | 41.6% |
| 패시브 스코어 | 항목 없음 | 항목 없음 확인 |
| 보드: 원시 증가량 버림 | **5.3%** | **5.3% — 일치** |
| 보드: 액티브 표시값 차감 | **5.3%** | **5.3% — 일치** |
| 보드: 원시 증가량 반올림 | **5.4%** | **5.3% — 실패** |

패시브 숫자 필드는 null로 보존하고 항목 없음은 별도 상태로 기록했다. 표시 기여 비교에서만 확인된 부재를 0으로 취급한다. 직전 표에 없었던 전체 종합력과 총 스코어 보너스는 미제공으로 남긴다. 멤버+패시브 종합력 **88,990**, 확인된 스코어 항목 합 **71.3+5.3+41.6=118.2%**는 계산한 합이다.

기본 액티브·SP 후보는 **28건·서로 다른 멤버 조합 19개**를 재현한다. SP 정밀도 규칙 발견 당시 20건은 사후 비교, W/AA/AB/AC/AD는 이후 새 멤버 조합 확인, X/Y/Z는 같은 멤버의 리더 변경 확인이다. 모든 관측을 독립 사전 예측 성공으로 세지 않는다.

## 남은 두 표시 처리 후보

AD에서 계산한 기본 액티브 원시값은 **71.2179531**, 보드 반영 원시값은 **76.5906295**이며 차이는 **5.3726764**다. 이는 연구 후보의 계산값으로, 게임 내부 원시값을 직접 관측한 것은 아니다.

| 방식 | AC 예측 / 실측 | AD 예측 / 실측 | 현재 상태 |
|---|---|---|---|
| 원시 증가량 버림 | 1.5 / 1.5 | 5.3 / 5.3 | 유지 |
| 반영 전후 액티브 각각 올림 후 차감 | 1.5 / 1.5 | 76.6−71.3 = 5.3 / 5.3 | 유지 |
| 원시 증가량 반올림 | 1.5 / 1.5 | 5.4 / 5.3 | AD에서 실패 |

세 방식은 AC를 본 뒤 비교한 후보들이다. AD는 이 중 두 후보가 처음으로 사전 구분 검증을 통과한 사례다. 같은 결과에 맞는 두 식이 남았으므로 아직 하나를 선택하지 않는다. 원시 증가량을 올리는 더 이전 후보는 AC에서 이미 실패했으며 다시 채택하지 않는다.

AC→AD는 같은 멤버 캐릭터와 보드 입력을 유지하면서 카나데 카드만 바꾼 비교다. 두 편성 모두 서포트 패시브는 없으며, 종합력 패시브와 멤버 보드는 남아 있다. 이번 결과를 Z/AA/AB의 양의 패시브·보드 배분식이나 아야메 스코어 서포트 의상 계산의 완성으로 확대하지 않는다.

## 다음 AE 사전 계획

AD의 **일반 후레아 11/0을 수영복 노엘 80/1로만 교체**한다.

| 역할 | 카드 | 레벨/개화 |
|---|---|---|
| 리더 | 수영복 스이세이 | 60/0 |
| 멤버 | 아야메 | 40/0 |
| 멤버 | 토와 | 70/0 |
| 멤버 | 라덴 | 70/1 |
| 멤버 | **수영복 노엘** | **80/1** |
| 멤버 | 수영복 카나데 | 40/0 |

노엘 외에 다른 3기생이 없으므로 노엘의 서포트 패시브와 SP 발동률 상승 조건은 불충족이다. 따라서 서포트 패시브 없음, 스이세이 의상 조건 불충족, 관련 리더 보드 없음이 유지된다. 같은 악곡 선택 전 화면에서 아야메 가창자 효과를 제외하고, 라덴 라이프 조건은 기존처럼 충족으로 계산한다.

이번에는 캐릭터도 바뀌므로 보드 입력이 후레아 발동률 6%/빈도 0%에서 노엘 23.5%/4%로 바뀐다. 두 입력 모두 기존에 제공되고 재확인된 수치다. 이 변화는 후보에 명시적으로 반영하며, AC→AD와 같은 보드 고정 비교라고 부르지 않는다.

| AE 사전 예측 | 값 |
|---|---:|
| 멤버 파라미터 | **92,663** |
| 패시브 종합력 | **11,520** |
| 의상 종합력 | 0 |
| 위 세 종합력 항목 합 | 104,183 |
| 액티브 | **73.3%** |
| SP | **41.3%** |
| 패시브 스코어 | **0 또는 항목 없음** |
| 보드: 원시 증가량 버림 | **4.8%** |
| 보드: 액티브 표시값 차감 | **4.9%** |

AE 후보의 기본 액티브 원시값은 **73.2777290**, 보드 반영 원시값은 **78.1639955**, 차이는 **4.8862665**다. 원시 증가량 버림은 4.8%, 액티브 표시값 차감은 **78.2−73.3=4.9%**다.

- **4.8%**라면 현재 원시 계산을 전제로 버림 후보를 지지한다.
- **4.9%**라면 같은 전제에서 액티브 표시값 차감 후보를 지지한다. 이미 실패한 반올림·올림 후보가 이 편성에서 우연히 4.9를 내더라도 과거 실패를 취소하지 않는다.
- **다른 값**이면 새 오차를 그대로 기록하고 원시 계산·적용 조건을 재검토한다.

AE의 다섯 멤버는 기존 **R 편성**과 같고 리더만 리리카에서 스이세이로 다르다. 따라서 액티브 73.3%·SP 41.3%·멤버 파라미터·패시브 종합력은 R에서도 확인된 값이다. AE는 스이세이 리더에서의 새로운 보드 표시 검증이며, 새로운 고유 멤버 조합으로 세지 않는다.

다른 스코어 기여가 없다면 항목 합은 보드 4.8일 때 **119.4%**, 보드 4.9일 때 **119.5%**다. AE에서는 **멤버 파라미터·패시브 종합력·액티브·SP·정확한 보드 표시값·패시브 항목 유무**를 확인하고, 총 보너스가 제공되면 합도 검산한다.
