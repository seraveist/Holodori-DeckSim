# AZ 사전 예측 일치 — 노엘 발동률 없는 기준점

2026-09-09. 사용자 원문은 “모두 일치함.”이다. 악곡 선택 전 AX와 같은 카드·레벨로 노엘의 남은 발동률11.1%·3.7%·3.0%를 모두 끄는 AZ를 요청했다. 노엘 빈도와 카나데 발동률은 계속OFF, 리리카 서포트13.3%·판정 노드ON을 유지하는 절차다.

| 항목 | 사전 예측 | 실측 |
|---|---:|---:|
| 액티브 | 68.9% | 68.9% |
| SP | 37.5% | 37.5% |
| 패시브 | 항목 없음 | 항목 없음 |
| 보드 | 9.2% | 9.2% |

예측 파일을 먼저 생성하고 사용자에게 수치를 제시한 뒤 답변을 받았다. Git 포장은 답변 이후다. `baseline-noel-off-AZ-20260909.json`의 미관측 상태는 당시의 고정 계획이므로 바꾸지 않고 별도 AZ 관측·상태 파일을 추가했다. 종합력·총합은 확인하지 않았다. 연결로 인한 추가 효과 변경은 보고되지 않았고 별도 화면 감사는 없다.

AX는 동일 편성에서 노엘 발동률17.8%가ON이며 보드10.9%였다. 따라서 노엘 발동률을 켠 표시 증가량은 실측1.7%p, 현재 모형1.6%p다. 발동률OFF의 기준점이 맞으므로 AX의 차이는 해당 발동률을 적용할 때 드러나는 쪽으로 좁혀진다. 이것만으로 원인이 발동확률의 정밀도, 중첩 정규화, 판정 노드와의 상호작용 중 무엇인지 확정되지는 않는다. 패시브 배분과 무관한 차이라는 판단은 유지한다.

새 모형의 사전 검증은 **AV/AW/AY/AZ 성공, AX 실패로4/5**다. 이 다섯 조건은 서로 다른 멤버 조합3개이고 나머지는 보드 개입이다. 모형 선택에 쓴40건과 합치면 적용 대상45건 중44건을 재현하지만, 무작위 표본의 정확도로 표현하지 않는다. AX 보드10.8 예측·10.9 관측은 그대로 실패로 남긴다. 최종 반올림12설정 검사는 AZ 관측 전44건 대상으로 한 고정 진단이다.

최신 집계는 **49관측·26멤버 조합, 액티브45/45·SP45/45, 기본 종합력 확인106개, 양의 패시브 원시 합계 호환32건**이다. 서포트 의상 I/J/M과 리더 보드 미확인 U는 새 보드 모형의 적용 집계에서 계속 제외하며 AU도 미관측이다. 서비스 계산식은 변경하지 않았다.

다음 연구에서는 AX/AZ를 대조 기준으로 노엘 발동률을 반영하는 연산을 살핀다. 추가 실측이 필요하면 연결 가능한 중간 발동률 상태를 정하고 예측을 별도로 고정한다. AX 한 건에 맞춘 상수나, 답변을 본 뒤 바꾼 예측을 사전 검증 성공으로 인정하지 않는다.

`node scripts/test-validation-az.mjs`로 이번 결과와 집계를, `node verify-handoff.mjs`로 이전 실패·원문·계획의 해시까지 재현한다. 최신 목록은 `analysis/unit-score/observation-catalog-AZ-20260909.json`이다.
