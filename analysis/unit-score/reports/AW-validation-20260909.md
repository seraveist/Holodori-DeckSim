# AW 확인과 와타메 보드OFF 대조 AY

2026-09-09. 사용자 원문: **“일단 AW는 모두 일치하는걸 확인했어. 다음으로 와타메의 보드만 끄고 다시 알려줄께.”**

직전 사용자에게 제시한 표의 네 스코어 항목을 확인한 것으로 기록한다. 문서에만 있던 종합력 세 항목이나 전체 총합까지 확인한 것으로 확대하지 않는다. 별도 스크린샷·카드 레벨·노드별 감사 자료는 제공되지 않았다.

| AW 항목 | 사전 예측 | 사용자 확인 |
|---|---:|---:|
| 액티브 | 74.0% | 일치 |
| SP | 42.9% | 일치 |
| 패시브 | 4.7% | 일치 |
| 홀로멤 보드 | 11.3% | 일치 |

확률·효과량 중간 올림 후보의 **첫 사전 예측 성공1/1**이다. 기존40건은 계속 사후 재현으로 구분한다. AW는 기존23개와 다른 멤버 조합이다. 확률 합 분모 버림 대안도 AW와 일치하므로 한 번의 성공으로 유일한 내부식을 확정하지 않는다. 효과량만 올리는 대안의 보드11.2%는 이번 사전 대조에서 맞지 않았다.

AV를 먼저 요청했지만 사용자가 AW를 먼저 확인했다. **AV·AX·AU는 미관측**이며 순서를 추정해 채우지 않는다. 계획과 예측표는 답변 전에 제시했으나 Git 포장은 이 답변 이후 이루어진다.

## 다음 AY — 같은 AW에서 와타메 발동 관련 효과만 OFF

편성과 육성은 유지한다.

- 리리카3성 「We are hololive!」1/0 리더.
- 수영복 스이세이60/0 → 수영복 노엘80/1 → 일반 카나데 「퍼레이드로 미소를 전달」80/0 → 수영복 후레아 「sparks sunset」80/1 → 수영복 와타메70/1.
- 와타메 발동률11.1%·3.7%·3%·3%·3.7%(합24.5%)와 발동빈도4%를OFF.
- 노엘 발동률17.8%/빈도0%, 카나데 발동률0%, 후레아6%, 리리카 서포트13.3%·판정 노드ON은 AW 그대로 유지.
- 전체 보드 초기화로 다른 효과까지 바뀌었다면 그 변경을 별도로 기록한다. 현재 예측은 지정한 발동률·빈도만 제거한 조건이다.

**AY 사전 예측: 액티브74.0% / SP42.9% / 패시브7.0% / 홀로멤 보드12.0%.**

표시 패시브·보드의 합은 AW16.0%에서 AY19.0%로 증가한다. 현재200초 표본 모형에서는 주기가 원래대로 돌아오며 스킬 중첩·정규화가 달라져 이 증가를 예측한다. 직관과 반대일 수 있는 수치도 결과 전에 고정한다. 실제 곡에서 보드를 끄면 점수가 좋아진다는 뜻은 아니다.

예측 파일은 `experiments/baseline-watame-AY-20260909.json`이다. 관측이 도착하면 먼저 원문·노드 조건을 기록하고, 이 예측과 비교한 뒤 가설을 평가한다. 유리한 결과에 맞춰 전체 보드OFF와 발동 관련 노드만OFF를 혼용하지 않는다.

누적45건·24개 멤버 조합, 액티브/SP41/41, 기본 종합력 확인106개를 유지한다. AW의 종합력은null이다. 새 모형은 기존40건 사후 재현+AW1건 사전 성공으로 구분한다. 서비스 계산식은 변경하지 않았다.
